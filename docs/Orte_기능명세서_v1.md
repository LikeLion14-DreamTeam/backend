# 0. 프로덕트 요구사항

**사용자 시나리오**

[최초 1회 · 2분 · 영구 방지] 사용자는 구글 계정으로 로그인한 뒤 기본 질문 7개에 답하고, 사진 A/B 페어 5쌍을 톡-톡 방식으로 선택한다(“어떤 사진을 좋아하세요?”라고 말로 묻지 않고 두 장 중 고르게 한다). 시스템은 선택 행동에서 6종 축 가중치를 추출해 취향 프로파일을 생성한다. [여행 중 · 0.5초/회 · 1차 방지] 여행지 골목에서 인상 깊은 순간, 가방/참에 폰을 톡 댄다 → 웹이 즉시 실행되고(앱 설치·로그인 없음, 잠금 상태에서도 작동) 카메라가 열린다 → 촬영 → 저장 완료 화면에서 한 줄 텍스트와 음성 메모를 함께 또는 각각 남김 → 저장 완료, 같은 자리에서 계속 촬영하거나 홈으로 돌아간다. 백그라운드에서 지도에 핀 1개가 생성된다. [여행 종료 시 · 자동 처리] 시스템이 핀 구간별로 perceptual hash + 시간 근접도로 유사 중복 컷을 제거하고, 남은 컷을 취향 가중치로 스코어링해 핀별 대표 컷 3장을 확정한다. 음성은 텍스트로 변환되어 캡션·챕터 제목 생성에 쓰인다. [되돌려받기 · 3개 뷰] 지도에서 핀 7개와 촬영량에 따라 농도가 다른 갈색 동선이 이미 꽂혀 있고, 핀을 누르면 그날의 음성이 재생되고 12장이 이미 골라져 있다(전부 얼굴이 작게 나온 컷 — 온보딩에서 그렇게 골랐기 때문). 홈에 들어가면 여권이 펼쳐지며 도장이 하나 늘어 있다. 여정을 마치고 홈에서 여정 종료하기를 누르면 여정별·도시별 포토북이 생성되고, 여행 사이에는 여권 도장을 다시 열어본다. [피드백 루프 · 전환비용] 사용자가 추천에서 뺀 컷·더한 컷이 프로파일을 갱신하여 다음 여행엔 더 정확해진다. [회수 · 매장] MCM 매장 카운터에 가방을 댄다 → 스크린에 그 12장이 뜬다 → 포토북 인화·포토카드·참에 도시명·날짜 각인이 이루어진다(“기계가 고른 게 아니라, 당신 기준으로 고른 것이다”).

- **카테고리**: 라이프스타일 / 일상
- **사용자 역할**: 여행자
- **디바이스**: 모바일 웹

# 1~8. 기능 상세


## 1 계정·인증 및 권한
여행자는 구글 계정으로 서비스에 로그인해 자신의 취향 프로파일, 여행 핀, 추천 결과, 포토북 기록을 개인 계정 데이터로 이용하며, 여행 기록과 맥락 입력에 필요한 카메라·위치·마이크 권한의 목적을 확인하고 허용하거나 거부하며, 안드로이드 기기에서는 NFC가 켜져 있는지 확인하라는 안내를 함께 확인한다. 이 영역은 구글 로그인, 세션 유지·해제, 권한 안내·요청, 권한 거부·미지원 안내를 포함하며 이메일·비밀번호 회원가입과 계정 삭제 흐름은 포함하지 않는다.
- 여행자는 구글 계정으로 서비스에 로그인할 수 있다.
- 로그인한 여행자는 자신의 취향 프로파일, 핀, 추천 결과, 포토북을 개인 계정 데이터로 조회할 수 있다.
- 여행자는 로그아웃 후 다시 로그인해도 이전 계정 데이터에 그대로 접근할 수 있다.
- 여행자는 카메라·위치·마이크 권한 요청의 목적을 확인하고 허용 또는 거부할 수 있으며, 안드로이드 기기에서는 NFC 활성화 확인 안내를 볼 수 있다.
- 필수 권한이 거부되었거나 기기에서 지원되지 않는 경우, 서비스는 사용할 수 없는 기능과 설정 방법을 안내한다.

### 1.1 구글 로그인
여행자는 구글 계정으로 서비스에 로그인해 본인의 취향 프로파일·핀·추천 결과·포토북을 개인 계정으로 이용하고, 로그아웃 후에도 다시 로그인하면 기록에 이어서 접근한다. 이 기능은 구글 OAuth 로그인과 세션 유지·해제에 한정하며 이메일·비밀번호 회원가입과 계정 삭제는 포함하지 않는다.

**기능의 근거**

 여행자는 기기가 바뀌거나 재설치해도 자신의 취향 프로파일과 여행 기록에 다시 접근할 수 있어야 한다. 구글 로그인은 별도 회원가입 단계 없이 개인 계정을 식별해 데이터를 이어준다.

**성공 기준**

 로그인 성공률과 로그인 사용자의 재방문률을 측정한다.

**개발 준비 슬롯**

**선행조건**
- 여행자는 로그인에 사용할 구글 계정을 보유한다.

**트리거**
- 여행자가 로그인 화면의 구글로 계속하기 버튼을 선택한다.

**동작**
- 서비스는 구글 OAuth 동의 화면을 열어 여행자의 계정 선택과 권한 동의를 받는다.
- 서비스는 동의 화면에서 요청 권한(이메일 주소, 프로필 정보, 계정 식별자)과 사용 목적을 함께 안내한다.
- 서비스는 동의 결과로 사용자 식별자를 확보해 계정을 조회하거나 생성한다.
- 서비스는 로그인 세션을 발급해 이후 요청을 인증된 상태로 처리한다.

**결과**
- 서비스는 여행자의 계정을 인증된 상태로 유지한다.
- 서비스는 로그인 성공 이벤트와 계정 식별자 연결을 기록한다.
- 로그인한 여행자는 본인의 취향 프로파일, 핀, 추천 결과, 포토북에 접근한다.
- 최초 로그인 사용자는 취향 프로파일 온보딩(2)으로 이동하고, 온보딩을 완료한 사용자는 홈(3)으로 이동한다.

**예외**
- 서비스는 구글 동의가 거부되면 필요한 권한을 안내하고 다시 시도하도록 유도한다.
- 서비스는 로그인 실패 시 재시도 안내를 표시한다.

**표시**
- 로그인 화면에는 서비스명 Orte와 태그라인 “당신의 순간을 생생하게 남겨보세요”를 표시한다.
- 로그인 화면 하단에는 구글로 계속하기 버튼과, 구글 계정으로 로그인하면 취향 프로파일과 여행 기록을 저장할 수 있다는 안내 문구를 표시한다.
- 로그인 처리 중에는 처리 중 상태를 표시하고 버튼의 중복 선택을 막는다.
- 로그인에 실패하면 사용자에게 실패 사유와 후속 행동을 안내하는 문구를 표시한다.

**권한 & 접근**
- 로그인하지 않은 사용자는 로그인 화면만 이용할 수 있다.
- 로그인한 사용자는 본인의 계정 데이터만 조회할 수 있다.

**비즈니스 규칙**
- 이 서비스의 로그인 수단은 구글 계정으로 한정한다.
- 동일한 구글 계정으로 다시 로그인하면 기존 계정 데이터에 이어서 접근한다.
- 서비스는 로그아웃 전까지 로그인 세션을 유지한다.

**데이터**
- 계정에는 사용자 식별자, 구글 계정 식별자, 이메일, 표시 이름, 생성 시각, 마지막 로그인 시각, 온보딩 완료 여부를 저장한다.
- 세션에는 세션 식별자, 사용자 식별자, 발급 시각, 만료 시각을 저장한다.

#### 1.1.1 로그아웃 및 로그인 세션 해제
로그인한 여행자는 마이페이지의 로그아웃 동작을 통해 현재 기기의 로그인 세션을 해제한다. 로그아웃 후에는 개인 취향 프로파일과 여행 기록에 접근할 수 없으며, 같은 구글 계정으로 다시 로그인하면 기존 데이터를 이어서 이용한다.

**개발 준비 슬롯**

**선행조건**
- 여행자는 구글 계정으로 로그인한 활성 세션을 보유한다.

**트리거**
- 여행자가 마이페이지의 계정 영역에서 로그아웃을 선택한다.

**동작**
- 서비스는 현재 기기의 인증 세션을 무효화한다.
- 서비스는 개인 데이터에 접근하는 화면에서 로그인 화면으로 이동한다.

**결과**
- 여행자는 현재 기기에서 로그아웃된 상태가 된다.
- 서비스는 로그아웃 이벤트를 기록한다.
- 여행자의 취향 프로파일, 핀, 추천 결과, 포토북 데이터는 계정에 보존한다.

**예외**
- 로그아웃 처리 중 네트워크 요청이 실패해도 서비스는 현재 기기에 저장된 인증 정보를 제거한다.
- 이미 만료된 세션에서 로그아웃을 요청하면 서비스는 로그인 화면으로 이동한다.

**표시**
- 로그아웃 선택 시 서비스는 로그아웃 완료 메시지와 로그인 화면을 표시한다.

**권한 & 접근**
- 로그인한 여행자만 자신의 현재 세션을 로그아웃할 수 있다.

**비즈니스 규칙**
- 로그아웃은 현재 기기의 세션만 해제하며 계정 데이터와 다른 기기의 세션을 삭제하지 않는다.
- 로그아웃 후 개인 데이터 화면에 접근하려면 다시 로그인해야 한다.

**데이터**
- 세션에는 사용자 식별자, 세션 식별자, 발급 시각, 만료 시각, 무효화 시각을 저장한다.
- 로그아웃 이벤트에는 사용자 식별자, 세션 식별자, 처리 시각을 저장한다.

### 1.2 촬영·위치·마이크 권한 안내 및 요청과 NFC 활성화 안내
여행자는 NFC 태깅과 핀 저장, 맥락 입력에 필요한 카메라·위치·마이크 접근 권한의 사용 목적을 권한 안내 화면에서 확인한 뒤 허용하거나 거부한다. NFC는 기기 권한 요청 대상이 아니므로, 안드로이드 기기에서만 NFC가 켜져 있는지 확인하라는 안내를 같은 화면에 표시한다. 이 기능은 권한 종류별 목적 안내와 기기 권한 요청, NFC 활성화 안내에 한정하며, 거부·미지원 상태의 후속 안내는 1.3에서 다룬다.

**기능의 근거**

 여행 중 촬영 순간에 권한 요청 팝업이 처음 뜨면 사용자는 판단할 시간이 없어 반사적으로 거부하기 쉽다. 사용 목적을 미리 설명한 뒤 요청하면 허용률이 올라가고, 태깅하지 않은 사진·위치를 수집하지 않는다는 원칙을 사용자에게 먼저 전달할 수 있다. 또한 안드로이드는 기기 설정의 NFC가 꺼져 있으면 태그를 인식하지 못하는데, 이는 앱이 권한으로 해결할 수 없는 영역이므로 여행 전에 미리 확인시켜야 현장에서 태깅이 실패하는 상황을 줄일 수 있다.

**성공 기준**

 권한별 허용률과 권한 안내 화면 이탈률을 측정한다.

**개발 준비 슬롯**

**선행조건**
- 여행자는 로그인한 상태이다.

**트리거**
- 여행자가 온보딩 완료 후 처음 홈에 진입한다.
- 여행자가 NFC 태깅, 사진 촬영, 위치 확인, 음성 메모가 필요한 기능을 권한 미허용 상태에서 실행한다.

**동작**
- 서비스는 카메라·위치·마이크 각각의 사용 목적을 한 화면에 나열해 표시한다.
- 서비스는 접속 기기의 운영체제를 판별해 안드로이드인 경우에만 NFC 활성화 확인 안내 항목을 함께 표시한다.
- 서비스는 태깅하지 않은 사진이나 위치는 수집하지 않는다는 원칙을 함께 안내한다.
- 여행자가 권한 허용을 선택하면 서비스는 기기 운영체제의 카메라·위치·마이크 권한 요청을 순차로 호출한다.
- 서비스는 NFC에 대해서는 어떤 권한 요청도 호출하지 않는다.
- 여행자가 권한을 허용하지 않으면 어떻게 되는지 묻는 진입점을 선택하면 서비스는 1.3 권한 거부·미지원 안내로 이동한다.

**결과**
- 허용된 권한 상태는 이후 NFC 태깅과 핀 저장 실행에 사용된다.
- 서비스는 권한 요청, 허용, 거부, 미지원 상태 이벤트를 분석용으로 기록한다.

**예외**
- 하나 이상의 권한이 거부되면 1.3 권한 거부·미지원 안내로 이동한다.
- iOS 기기에서는 NFC 안내 항목을 표시하지 않으며, 별도 설정 없이 태그 인식이 동작하는 것으로 본다.
- 기기가 NFC를 지원하지 않으면 NFC 안내 항목을 표시하지 않고 1.3 권한 거부·미지원 안내의 대체 경로를 따른다.
- 마이크 권한이 거부되어도 권한 안내 화면은 통과시키며, 음성 메모만 사용할 수 없는 상태로 진행한다.
- 권한 요청 결과를 확인할 수 없으면 재시도 안내를 제공한다.

**표시**
- 화면은 카메라, 위치, 마이크 각각의 이름과 사용 목적 문구를 표시한다.
- 안드로이드 기기에서는 권한 목록 아래에 NFC 활성화 확인 안내를 별도 영역으로 표시하며, 허용·거부 선택지를 두지 않는다.
- NFC 안내 문구는 기기 설정에서 NFC가 켜져 있는지 확인해 달라는 내용으로 표시한다.
- 마이크 항목에는 촬영 직후 음성으로 맥락을 남기기 위해 사용한다는 목적과, 허용하지 않아도 텍스트 기록으로 대체할 수 있다는 안내를 함께 표시한다.
- 화면 하단에는 권한 허용하고 시작하기 버튼과 “권한을 허용하지 않으면 어떻게 되나요?” 진입점 두 가지만 표시한다.

**권한 & 접근**
- 여행자는 기기 운영체제의 권한 요청에서 각 권한을 허용하거나 거부할 수 있다.
- NFC는 기기 권한 체계의 요청 대상이 아니며, 사용 가능 여부는 기기 지원 여부와 운영체제 설정의 NFC 활성화 상태에 따라 결정된다.
- 안드로이드는 사용자가 기기 설정에서 NFC를 직접 켜야 하며, iOS는 별도 설정 없이 태그 인식이 동작한다.

**비즈니스 규칙**
- 서비스는 NFC 태깅과 핀 저장, 맥락 입력에 필요한 범위에서만 카메라·위치·마이크 접근을 요청한다.
- 카메라는 필수 권한이며, 위치와 마이크는 선택 권한으로 거부해도 서비스 이용을 차단하지 않는다.
- 서비스는 음성 메모를 녹음하는 시점에만 마이크를 사용하며 상시 녹음하지 않는다.
- 서비스는 태깅하지 않은 사진을 백그라운드에서 자동 수집하거나 지속적으로 위치를 추적하지 않는다.
- 권한 안내 화면은 계정당 1회 표시하며, 이후에는 권한이 필요한 기능 실행 시점에만 다시 표시한다.
- 서비스는 NFC를 권한 요청 대상으로 다루지 않으며, 안내 표시 외의 처리를 하지 않는다.

**데이터**
- 권한 상태는 여행자 기기에서 카메라, 위치, 마이크별 허용·거부·미지원 상태로 조회한다. **[v3.5 변경]**- NFC는 권한 상태를 조회하지 않으며, 안내 표시 여부 판단에 운영체제 구분과 기기 지원 여부만 사용한다. **[v3.5 신설]**- 서비스는 권한 안내 화면 표시 여부를 계정 단위로 저장한다.

### 1.3 권한 거부·미지원 안내 및 재시도
여행자가 권한을 거부했거나 기기가 NFC를 지원하지 않는 경우, 서비스는 사용할 수 없는 기능과 기기 설정으로 이동하는 방법을 권한별로 안내하고 재시도 진입점을 제공한다. 이 기능은 거부·미지원 상태의 안내와 재요청에 한정하며, 최초 권한 요청은 1.2에서 다룬다.

**기능의 근거**

 권한을 거부한 사용자가 어떤 기능을 쓸 수 없게 되는지 모르면 서비스를 그대로 이탈한다. 권한별로 잃는 기능을 구체적으로 알리고 설정 이동 경로를 제공하면 복구 가능성이 생긴다.

**성공 기준**

 권한 거부 후 재요청을 통한 허용 전환율을 측정한다.

**개발 준비 슬롯**

**선행조건**
- 하나 이상의 권한이 거부되었거나 기기가 해당 권한을 지원하지 않는다.

**트리거**
- 1.2에서 권한 요청 결과가 거부로 확인된다.
- 여행자가 권한이 필요한 기능에 권한 미허용 상태로 진입한다.

**동작**
- 서비스는 거부되거나 미지원 상태인 권한만 골라 목록으로 표시한다.
- 서비스는 권한별로 사용할 수 없게 되는 기능을 구체적으로 설명한다.
- 여행자가 권한별 설정으로 이동을 선택하면 서비스는 기기 설정 화면으로 이동하도록 안내한다.

**결과**
- 여행자는 사용할 수 없는 기능과 복구 방법을 확인한다.
- 서비스는 권한 거부 안내 노출 이벤트와 설정 이동 선택 이벤트를 기록한다.

**예외**
- 카메라 권한이 거부되면 NFC 태깅 후 사진 촬영을 실행하지 않는다.
- 위치 권한이 거부되면 좌표 없이 핀을 저장하고, 해당 핀은 지도와 동선에서 제외한 뒤 4.1 여행 구간 관리의 포함된 핀 목록에 위치 정보 없음 상태로 표시한다.
- 마이크 권한이 거부되면 8.2 핀 저장 및 맥락 입력에서 음성 메모 진입점을 비활성 상태로 표시하고 텍스트 기록만 제공한다.
- 기기가 NFC를 지원하지 않으면 NFC 태깅을 시작하지 않고 3.3 여행 계속하기 또는 5.1.2 지도에서 핀 수동 입력을 대체 경로로 안내한다.

**표시**
- 화면은 권한 이름, 사용할 수 없는 기능 설명, 설정으로 이동 버튼을 권한마다 표시한다.
- 화면 하단에는 권한 거부 상태에서도 이용 가능한 기능이 있다는 안내와 이전 화면으로 돌아가기 진입점을 표시한다.

**권한 & 접근**
- 권한의 최종 허용 여부는 기기 운영체제 설정에서 결정된다.

**비즈니스 규칙**
- 서비스는 권한을 거부한 사용자의 서비스 이용 자체를 차단하지 않는다.
- 위치 권한 거부 상태에서도 사진 촬영과 핀 저장은 가능하며 좌표만 저장하지 않는다.
- 마이크 권한 거부 상태에서도 사진 촬영과 핀 저장은 가능하며 맥락 입력을 텍스트 기록으로만 수행한다.

**데이터**
- 권한 상태는 여행자 기기에서 카메라, 위치, 마이크별 허용·거부·미지원 상태로 조회한다. **[v3.5 변경]**- NFC는 권한 상태 대신 기기 지원 여부만 확인한다. **[v3.5 신설]**- 서비스는 권한 상태를 핀 저장 가능 여부와 지도 표시 가능 여부 판단에 사용한다.

## 2 취향 프로파일 온보딩
서비스는 여행자가 기본 질문과 사진 A/B 선택을 통해 자신의 여행 사진 선호 기준을 설정하도록 지원한다. 이 영역은 최초 이용자의 취향 프로파일 생성과 중단한 온보딩의 재개를 포함하며, 기존 개인 앨범을 자동 분석하는 방식은 포함하지 않는다.
- 여행자는 최초 이용 시 사진 취향을 파악하는 기본 질문 7개에 답할 수 있다.
- 여행자는 차이가 뚜렷한 사진 A/B 쌍 5회 선택을 통해 취향 프로파일을 생성할 수 있다.
- 여행자는 무드보드 9장 중 3장 선택을 2회 수행해 취향 프로파일을 보완할 수 있다.
- 온보딩 화면에서 사진과 전체 진행 상태를 확인할 수 있다.
- 온보딩을 중단한 여행자는 다음 진입 시 이전 진행 상태를 이어서 진행할 수 있다.
- 여행자는 온보딩의 어느 단계도 건너뛸 수 없으며, 모든 문항에 답해야 홈으로 진입할 수 있다.

### 2.1 기본 질문 취향 온보딩
여행자는 서비스가 제공하는 점진적 적응형 퀴즈 형식의 기본 질문 7개에 답해 여행 사진 촬영의 준거가 되는 초기 프로파일을 설정한다. 서비스는 이전 응답에 따라 다음 질문을 좁혀가며 인물·풍경, 구도, 분위기 등 핵심 축을 파악하며, A/B 사진 비교를 통한 보완은 포함하지 않는다.

**기능의 근거**

 사진 A/B 비교만으로는 여행자의 선호 테마와 상황적 맥락을 충분히 파악하기 어렵다. 서비스가 직접 던지는 기본 질문은 여행 유형·좋아하는 분위기·인물 등장 선호를 빠르게 물어 추천 정확도의 출발점을 만든다.

**성공 기준**

 기본 질문 온보딩 완료율을 측정한다.

**개발 준비 슬롯**

**선행조건**
- 여행자는 최초 취향 프로파일을 아직 생성하지 않았다.

**트리거**
- 여행자가 최초 로그인 직후 취향 설정을 시작한다.

**동작**
- 서비스는 첫 라운드에서 인물 중심·풍경 중심과 같은 큰 축을 묻는다.
- 서비스는 이전 응답에 따라 다음 라운드의 세부 축으로 질문을 좁혀 설계한다.
- 여행자는 각 라운드의 질문에 하나의 선택지를 골라 답한다.
- 서비스는 앞선 라운드에서 선택한 값을 화면 상단에 칩 형태로 누적 표시한다.
- 서비스는 라운드별 응답을 누적해 초기 취향 프로파일을 생성한다.

**결과**
- 서비스는 라운드별 응답을 결합해 초기 취향 프로파일을 생성한다.
- 생성된 초기 프로파일은 A/B 사진 온보딩과 무드보드 온보딩에서 이어서 보완된다.
- 서비스는 라운드별 질문 열람 이벤트와 응답 이벤트를 기록한다.

**예외**
- 응답 저장 또는 다음 질문 조회에 실패하면 현재 질문과 입력 상태를 유지하고 사용자가 재시도할 수 있게 한다.
- 동일 라운드의 연속 제출에서는 먼저 저장된 응답만 반영한다.

**표시**
- 한 화면에는 기본 질문 하나와 선택지 목록, 전체 진행 상태(현재 문항 / 전체 7)를 표시한다.
- 화면에는 건너뛰기 진입점을 표시하지 않는다.
- 화면 상단에는 이전 라운드에서 선택한 값을 칩으로 표시한다.
- 다음 질문을 불러오는 동안 처리 중 상태를 표시한다.

**권한 & 접근**
- 기본 질문 취향 온보딩은 로그인한 여행자에게만 제공한다.

**비즈니스 규칙**
- 기본 질문은 7개로 구성한다.
- 기본 질문에는 건너뛰기를 제공하지 않으며, 7개 문항에 모두 답해야 다음 단계로 진행한다.
- 기본 질문은 점진적 적응형 퀴즈 형식으로, 이전 응답에 따라 다음 질문이 상위 축에서 세부 축으로 좁혀진다.
- 첫 라운드는 인물 중심·풍경 중심 같은 큰 축을 물어 상위 선호를 파악한다.
- 이후 라운드는 인물 선호 서브 축(클로즈업 vs 전신, 포즈 vs 자연스러운 순간)과 풍경 선호 서브 축(광각 vs 클로즈업, 낮·밤 분위기)으로 좁혀진다.
- 모든 라운드에서 구도·분위기 등 공통 축도 함께 수집한다.
- 기본 질문 온보딩 완료 후 A/B 사진 온보딩으로 이어진다.

**데이터**
- 기본 질문 응답에는 라운드, 문항 식별자, 상위 축, 선택값, 응답 시각을 저장한다.
- 초기 프로파일에는 인물 중심·풍경 중심 비율, 인물 구성(클로즈업·전신, 포즈·자연스러운 순간), 풍경 구성(광각·클로즈업, 시간대 분위기), 구도·분위기 선호를 보관한다.

### 2.2 A/B 사진 취향 온보딩
여행자는 차이가 뚜렷한 사진 A/B 쌍을 5회 선택해 자신의 여행 사진 선별 기준을 설정한다. 각 라운드는 기본 질문으로 파악한 상위 축 안에서 사진으로만 판단할 수 있는 세부 축(색감, 구도 밀도, 분위기 등)을 검증하는 사진 쌍으로 구성하며, 기본 질문 응답 수집과 기존 개인 앨범 자동 분석은 포함하지 않는다.

**기능의 근거**

 사용자가 말로 설명하는 취향과 실제로 고르는 사진은 다르다. 두 장 중 하나를 고르게 하는 방식은 언어화 과정을 건너뛰고 선택 행동 자체를 취향 신호로 확보한다.

**성공 기준**

 A/B 온보딩 완주율과 라운드별 선택 소요 시간을 측정한다.

**개발 준비 슬롯**

**선행조건**
- 여행자는 기본 질문 온보딩을 완료했다.

**트리거**
- 기본 질문 온보딩 완료 직후 서비스가 A/B 사진 선택을 시작한다.

**동작**
- 서비스는 기본 질문 온보딩에서 파악한 상위 축(예: 인물 중심)에 맞춰 A/B 사진 5쌍을 순차 제시한다.
- 여행자는 각 쌍에서 더 선호하는 한 장을 선택한다.
- 서비스는 선택 즉시 다음 사진 쌍으로 전환한다.
- 여행자가 이전 사진 진입점을 선택하면 서비스는 직전 사진 쌍으로 돌아가 선택을 다시 받는다.
- 서비스는 각 라운드에서 검증하려는 세부 축(색감, 구도 밀도, 분위기 등)을 구분해 선택 로그를 기록한다.
- 서비스는 5회 선택 결과를 누적해 기존 취향 프로파일에 보완 반영한다.

**결과**
- 서비스는 기본 질문 응답과 A/B 선택 로그를 결합해 취향 프로파일을 갱신한다.
- A/B 온보딩 완료 후 2.3 무드보드 취향 온보딩으로 이어진다.

**예외**
- 온보딩을 중단한 사용자는 다음 진입 시 마지막 선택 지점부터 다시 진행한다.
- 사진 로딩에 실패하면 해당 쌍을 건너뛰지 않고 재시도 안내를 표시한다.
- 첫 번째 라운드에서는 이전 사진 진입점을 표시하지 않는다.

**표시**
- 한 화면에는 비교할 사진 두 장과 진행 상태(현재 라운드 / 전체 5)를 표시한다.
- 사진 아래에는 이전 사진 진입점과, 선택하면 다음 사진 쌍으로 넘어간다는 안내 문구를 표시한다.
- 화면에는 건너뛰기 진입점을 표시하지 않는다.
- 사진을 불러오는 동안 처리 중 상태를 표시한다.

**권한 & 접근**
- 이 기능은 별도 기기 권한을 요구하지 않는다.

**비즈니스 규칙**
- 온보딩 순서는 기본 질문 → A/B 사진 → 무드보드 순으로 진행한다.
- 여행자는 이전 사진 진입점으로 직전 라운드까지만 되돌아갈 수 있다.
- A/B 사진 선택은 5회 제공한다.
- A/B 사진 선택에는 건너뛰기를 제공하지 않으며, 5쌍을 모두 선택해야 다음 단계로 진행한다.
- 각 라운드의 사진 쌍은 기본 질문으로 파악한 상위 축과 일치하는 범위 안에서 하나의 세부 축만 달라지도록 구성한다.
- 서비스는 범용 미학 점수가 아닌 사용자의 선택 행동을 취향 입력으로 사용한다.
- 온보딩에 사용하는 사진은 팀 자체 촬영본 또는 저작권 제약이 없는 이미지로 한정한다.

**데이터**
- 선택 로그에는 라운드, 사진 쌍 식별자, 검증 세부 축, 선택한 사진 식별자, 선택 시각을 저장한다.
- 프로파일 보완에는 상위 축 내 세부 선호(색감, 구도 밀도, 인물 크기, 얼굴 노출도, 분위기)를 반영한다.
- 5쌍은 색감 축, 구도 밀도 축, 분위기 축, 인물 크기 축, 순간 자연성 축을 각기 검증하는 구성을 기본으로 한다.

### 2.3 무드보드 취향 온보딩
여행자는 9장이 배치된 무드보드에서 마음에 드는 사진 3장을 선택하는 라운드를 2회 수행해 취향 프로파일을 보완한다. A/B 비교가 두 장 사이의 상대 선호를 확인한다면, 무드보드는 여러 후보 중 사용자가 실제로 끌리는 조합을 확인해 축의 조합 선호를 파악한다. 기본 질문 응답 수집과 기존 개인 앨범 자동 분석은 포함하지 않는다.

**기능의 근거**

 A/B 선택은 한 번에 하나의 축만 검증할 수 있어 여러 축이 동시에 작용하는 실제 선별 상황과 다르다. 여러 장을 한 화면에 놓고 고르게 하면 사용자가 무엇을 함께 좋아하는지가 드러나고, 단일 축으로는 잡히지 않는 조합 선호를 확보할 수 있다.

**성공 기준**

 무드보드 라운드 완주율과 라운드 간 선택 일관성을 측정한다.

**개발 준비 슬롯**

**선행조건**
- 여행자는 A/B 사진 취향 온보딩을 완료했다.

**트리거**
- A/B 사진 온보딩 완료 직후 서비스가 무드보드 라운드를 시작한다.

**동작**
- 서비스는 사진 9장을 3열 격자로 배치해 표시한다.
- 여행자는 마음에 드는 사진을 정확히 3장 선택한다.
- 서비스는 선택한 사진에 선택 상태를 표시하고, 3장을 채우면 다음 라운드로 진행할 수 있게 한다.
- 여행자가 다음 라운드로를 선택하면 서비스는 2라운드의 사진 9장을 새로 제시한다.
- 서비스는 2개 라운드의 선택 결과를 누적해 취향 프로파일에 반영한다.

**결과**
- 서비스는 기본 질문, A/B 선택, 무드보드 선택을 결합해 최종 취향 프로파일을 생성한다.
- 온보딩을 완료한 여행자는 홈으로 이동한다.
- 서비스는 라운드별 선택 이벤트와 무드보드 완료 이벤트를 기록한다.

**예외**
- 선택한 사진이 3장 미만이면 다음 라운드로를 진행할 수 없게 한다.
- 이미 3장을 선택한 상태에서 다른 사진을 선택하면 안내를 표시하고 선택을 반영하지 않는다.
- 선택한 사진을 다시 선택하면 선택을 해제한다.
- 온보딩을 중단한 여행자는 다음 진입 시 마지막 라운드부터 다시 진행한다.
- 사진 로딩에 실패하면 해당 자리를 유지하고 재시도 안내를 표시한다.

**표시**
- 화면 상단은 나만의 사진 감각 찾기라는 제목과 마음에 드는 사진 3장을 선택해 달라는 안내 문구를 표시한다.
- 제목 아래에는 라운드 인디케이터 2개를 표시하고 현재 라운드를 강조한다.
- 사진은 3열 격자로 9장을 표시하고 선택한 사진에는 선택 상태를 표시한다.
- 화면 하단에는 다음 라운드로 진입점을 표시한다.
- 화면에는 건너뛰기 진입점을 표시하지 않는다.
- 사진을 불러오는 동안 처리 중 상태를 표시한다.

**권한 & 접근**
- 이 기능은 별도 기기 권한을 요구하지 않는다.

**비즈니스 규칙**
- 무드보드는 2개 라운드로 구성하며, 라운드마다 사진 9장 중 3장을 선택한다.
- 무드보드에는 건너뛰기를 제공하지 않으며, 2개 라운드를 모두 완료해야 홈으로 진입한다.
- 라운드별 사진 9장은 서로 다른 축 조합을 대표하도록 구성한다.
- 2라운드의 사진 구성은 1라운드의 선택 결과를 반영해 결정한다.
- 무드보드 선택 결과는 A/B 선택과 동일한 취향 축 체계에 누적 반영한다.
- 온보딩 순서는 기본 질문 → A/B 사진 → 무드보드 순으로 진행한다.
- 온보딩에 사용하는 사진은 팀 자체 촬영본 또는 저작권 제약이 없는 이미지로 한정한다.

**데이터**
- 무드보드 선택 로그에는 라운드, 후보 사진 식별자 목록, 선택한 사진 식별자 3개, 사진별 축 속성, 선택 시각을 저장한다.
- 프로파일 보완에는 선택한 사진 3장이 공유하는 축 속성의 가중치를 반영한다.

### 2.4 온보딩 이어하기
온보딩을 중단한 여행자는 다음 진입 시 이전에 답한 지점부터 온보딩을 이어서 진행한다. 이 동작은 기본 질문 온보딩, A/B 사진 온보딩, 무드보드 온보딩 전체에 걸쳐 동일하게 적용되며, 이미 완료한 온보딩 흐름의 재시작은 포함하지 않는다.※ 화면 미설계 — 디자인 필요

**개발 준비 슬롯**

**선행조건**
- 여행자는 온보딩을 중단한 상태이며 최종 프로파일이 생성되지 않았다.

**트리거**
- 여행자가 온보딩 중단 이후 서비스에 다시 진입한다.

**동작**
- 서비스는 저장된 진행 상태를 조회해 마지막 응답 지점을 복원한다.
- 서비스는 다음 문항부터 온보딩을 재개한다.
- 여행자는 남은 질문, A/B 선택 또는 무드보드 라운드에 이어서 답한다.

**결과**
- 서비스는 이어서 진행된 응답을 누적해 온보딩을 완료한다.
- 서비스는 온보딩 재개 이벤트를 기록한다.

**예외**
- 저장된 진행 상태가 없으면 온보딩을 처음부터 시작한다.
- 이미 완료한 온보딩 흐름은 재시작하지 않는다.

**표시**
- 재개 화면은 이전 진행 상태를 보여주고 다음 문항으로 이어진다.

**권한 & 접근**
- 여행자는 본인의 온보딩 진행 상태만 이어서 진행할 수 있다.

**비즈니스 규칙**
- 온보딩 이어하기는 기본 질문, A/B 사진, 무드보드 온보딩 전체에 동일하게 적용한다.
- 온보딩 완료 후에는 이어하기를 제공하지 않는다.

**데이터**
- 진행 상태에는 여행자 식별자, 현재 단계(기본 질문 · A/B 사진 · 무드보드), 마지막 응답 문항 또는 라운드 식별자, 누적 응답, 갱신 시각을 저장한다.

## 3 홈
여행자는 홈 화면에서 진행 중인 여정 요약과 가상 여권 도장 페이지를 확인하고, 여행 기록의 주요 진입점으로 이동한다. 이 영역은 진행 중인 여정 요약과 여정 종료, 가상 여권 국가 방문 도장, 여행 계속하기를 포함하며, 여행 구간 관리와 포토북 상세 열람은 다른 영역에서 다루므로 포함하지 않는다. **[v3.5 변경]**
- 여행자는 홈에서 진행 중인 여정의 이름, 기간, 핀 수와 사진 수를 확인할 수 있다.
- 여행자는 홈에서 방문 도시가 표기된 국가별 여권 도장을 확인하고, 도장을 선택해 해당 국가의 핀만 표시된 지도로 이동할 수 있다.
- 여행자는 홈 상단의 여행 계속하기로 진행 중인 여정에 이어서 촬영을 시작할 수 있다.
- 여행자는 진행 중인 여정 카드에서 여정 종료하기를 선택해 여정을 직접 종료할 수 있다.

### 3.1 진행 중인 여정 요약
여행자는 홈 화면 상단에서 현재 진행 중인 여정의 이름, 기간, 누적 핀 수와 사진 수를 확인하고 여정을 종료한다. 여정은 첫 태깅 시점에 자동으로 시작되며, 여행자가 여정 종료하기를 선택할 때까지 계속된다. 이 기능은 진행 중인 여정 하나의 요약 표시와 종료 진입점 제공에 한정하며, 구간 편집과 종료된 여정의 열람은 6번 영역에서 진입한다. **[v3.5 변경]**

**기능의 근거**

 여행 중에는 지금까지 무엇이 쌓였는지 확인할 수단이 필요하고, 여행이 끝난 뒤에는 기록이 이어지고 있다는 사실 자체가 재방문의 이유가 된다. 홈 최상단의 요약은 태깅 결과가 실제로 누적되고 있음을 즉시 확인시켜 준다. 다만 진행 중인 여정은 아직 핀이 계속 늘어나는 상태이므로, 포함 범위를 편집하는 일은 여정이 끝난 뒤에 하는 것이 맞다.

**성공 기준**

 홈 재방문율과 진행 중인 여정 카드의 여정 종료하기 선택률을 측정한다. **[v3.5 변경]**

**개발 준비 슬롯**

**선행조건**
- 여행자는 로그인한 상태이다.

**트리거**
- 여행자가 홈 화면에 진입한다.

**동작**
- 서비스는 상태가 진행 중인 여행 구간을 진행 중인 여정으로 판별한다.
- 서비스는 해당 여정의 이름, 기간, 포함 핀 수, 연결된 사진 수를 집계해 카드로 표시한다.
- 서비스는 여정 이름이 입력되지 않았으면 해당 여정에 포함된 핀의 도시명을 나열해 이름 자리에 표시한다. **[v3.5 신설]**- 서비스는 진행 중인 여정 카드에 여행 구간 관리 진입점을 표시하지 않는다. **[v3.5 변경]**- 여행자가 여정 종료하기를 선택하면 서비스는 종료 확인 안내를 표시하고, 확인하면 해당 여정의 상태를 종료됨으로 변경한다.
- 서비스는 여정 종료 시점에 기간의 종료일을 확정한다. **[v3.5 신설]**- 서비스는 여정 종료를 트리거로 6.1.1 포토북 생성을 시작한다.

**결과**
- 여행자는 진행 중인 여정의 누적 상태를 홈에서 확인한다.
- 종료된 여정은 홈의 진행 중인 여정 카드에서 사라지고 6.1 포토북 아카이빙 목록에서 확인한다.
- 서비스는 홈 조회 이벤트와 여정 종료 이벤트를 기록한다. **[v3.5 변경]**

**예외**
- 진행 중인 여정이 없으면 아직 시작된 여행이 없다는 빈 상태와 3.3 여행 계속하기 진입점을 표시한다.
- 진행 중인 여정은 계정당 최대 1개이며, 이미 진행 중인 여정이 있으면 새 여정을 생성하지 않는다.
- 포함된 핀이 하나도 없는 여정은 종료할 수 없으며, 여정 종료하기 진입점을 비활성 상태로 표시한다.
- 좌표가 없거나 도시명을 도출할 수 없는 핀만 있으면 여정 이름 자리에 이름 없는 여행으로 표시한다. **[v3.5 신설]**

**표시**
- 카드에는 여정 이름, 기간, 핀 수, 사진 수, 여정 종료하기 진입점을 표시한다. **[v3.5 변경]**- 진행 중인 여정 카드에는 커버 이미지를 표시하지 않는다. **[v3.5 신설]**- 진행 중인 여정 카드에는 여행 구간 관리 진입점을 표시하지 않는다. **[v3.5 신설]**- 여정 종료하기를 선택하면 종료 후에는 이 여정에 이어서 촬영할 수 없고 포토북이 생성된다는 확인 안내를 표시한다.
- 카드 위쪽 나의 여행 기록 제목 우측에는 3.3 여행 계속하기 진입점을 표시한다.
- 홈 화면 하단에는 별도의 수동 시작 진입점을 두지 않는다.
- 집계를 불러오는 동안 처리 중 상태를 표시한다.

**권한 & 접근**
- 여행자는 본인의 여정만 조회할 수 있다.

**비즈니스 규칙**
- 여정은 진행 중과 종료됨 두 가지 상태를 가지며, 시간 경과로 상태가 바뀌지 않는다.
- 진행 중인 여정이 없는 상태에서 첫 태깅이 발생하면 여정이 자동으로 생성되어 진행 중 상태가 된다.
- 여정은 여행자가 여정 종료하기를 선택할 때만 종료 상태로 바뀐다.
- 종료한 여정은 다시 진행 중으로 되돌릴 수 없으며, 이후의 태깅은 새 여정을 생성한다.
- 진행 중인 여정은 여행 구간 관리를 제공하지 않으며, 구간 관리는 종료된 여정에 대해 6.1 포토북 아카이빙 목록에서만 진입한다. **[v3.5 신설]**- 여정 기간의 시작은 진행 중인 여정이 없는 상태에서 생성된 첫 태깅 핀의 생성 시각으로 한다. **[v3.5 신설]**- 여정 기간의 종료는 여정 종료하기를 선택한 시점 이전에 생성된 핀 중 가장 최근 핀의 생성 시각으로 하며, 종료 버튼을 누른 시각 자체는 사용하지 않는다. **[v3.5 신설]**- 진행 중인 여정의 기간은 첫 핀의 생성 시각부터 현재까지 생성된 마지막 핀의 시각까지로 표시한다. **[v3.5 신설]**- 여행자가 이름을 입력하지 않은 여정의 이름은 해당 여정에 포함된 핀의 도시명을 나열해 구성하며, 날짜는 포함하지 않는다. **[v3.5 신설]**- 도시명 나열 순서는 핀의 생성 시각 오름차순으로 하고, 같은 도시가 여러 번 등장해도 한 번만 표기한다. **[v3.5 신설]**- 도시명 나열은 쉼표로 구분하며, 핀이 추가되어 방문 도시가 늘어나면 이름을 다시 계산해 갱신한다. **[v3.5 신설]**- 여행자가 4.2에서 이름을 직접 입력하면 입력한 이름이 도시명 나열보다 우선한다. **[v3.5 신설]**

**데이터**
- 요약 집계에는 여행 구간 식별자, 구간 이름, 상태, 시작·종료 시각, 핀 수, 사진 수를 조회한다.
- 여정에는 사용자 입력 이름과 자동 생성 이름을 구분해 저장하며, 사용자 입력 이름이 비어 있으면 자동 생성 이름을 표시한다. **[v3.5 신설]**- 여정 상태는 진행 중 또는 종료됨으로 저장하며, 종료 시각을 함께 저장한다.

### 3.2 가상 여권 국가 방문 도장
여행자는 홈 화면의 가상 여권 페이지에서 핀이 하나 이상 저장된 국가마다 도장이 찍힌 형태로 방문 국가를 한눈에 확인한다. 도장을 선택하면 해당 국가로 필터링된 지도로 이동해 그 국가에 저장된 핀만 확인할 수 있다. 이 기능은 국가 단위의 방문 요약과 국가별 지도 진입에 한정하며, 도장 디자인 커스터마이징이나 국가 간 여행 통계 비교는 포함하지 않는다.

**기능의 근거**

 여행자는 여러 나라에 흩어진 핀 기록을 개별적으로 봐야 해서 자신이 다녀온 나라를 한눈에 파악하기 어렵다. 국가 단위 도장 요약은 여행 기록을 가장 상위 단위에서 회고하게 해주고, 도장에서 국가별 지도로 바로 들어가게 해 공간 탐색과 자연스럽게 연결한다.

**성공 기준**

 여권 도장 페이지 노출 대비 도장 선택률과 국가별 지도 진입률을 측정한다.

**개발 준비 슬롯**

**선행조건**
- 여행자는 로그인한 상태이다.
- 여행자에게 좌표가 있는 핀 기록이 하나 이상 있다.

**트리거**
- 여행자가 홈 화면에 진입한다.

**동작**
- 서비스는 여행자의 핀 기록 좌표를 국가 단위로 집계해 핀이 하나 이상 저장된 국가를 판별한다.
- 서비스는 홈 진입 시 닫힌 여권이 펼쳐지는 전환 연출과 함께 도장 페이지를 표시한다.
- 서비스는 판별된 국가마다 도장을 하나씩 배치하고, 도장 안에 해당 국가에서 방문한 도시명을 함께 표기한다.
- 여행자가 특정 국가 도장을 선택하면 서비스는 해당 국가로 필터링된 5.1 지도 뷰로 이동하며, 그 국가에 저장된 핀만 표시하고 동선은 표시하지 않는다.

**결과**
- 여행자는 방문한 국가 목록을 도장 형태로 확인한다.
- 여행자는 국가 도장 선택 후 해당 국가로 범위가 좁혀진 지도에서 그 국가의 핀을 확인한다. **[v3.5 변경]**- 서비스는 여권 페이지 조회 이벤트와 국가 도장 선택 이벤트를 기록한다.

**예외**
- 방문한 국가가 없으면 도장이 없는 빈 여권 페이지와 첫 태깅을 안내하는 문구를 표시한다.
- 좌표가 없는 핀은 국가 집계에서 제외한다.
- 도장 수가 한 페이지 용량을 넘으면 다음 페이지로 넘겨 표시한다.

**표시**
- 여권 페이지는 방문 국가마다 도장 이미지와 국가명, 해당 국가에서 방문한 도시명을 표시하며 날짜는 표시하지 않는다. **[v3.5 변경]**- 한 국가에서 방문한 도시가 여러 개이면 핀 수가 많은 순으로 최대 3개까지 표기하고, 그 이상은 외 N곳으로 표기한다.
- 도장 페이지는 펼쳐진 양면을 기본으로 표시한다.
- 집계를 불러오는 동안 처리 중 상태를 표시한다.

**권한 & 접근**
- 여행자는 본인의 핀 기록으로 집계된 국가 도장만 조회한다.

**비즈니스 규칙**
- 도장이 찍히는 최소 조건은 해당 국가에 저장된 핀이 1개 이상 존재하는 것이다.
- 국가별 지도는 5.1 지도 뷰의 핀 표시 방식을 사용하되 동선은 표시하지 않고, 해당 국가에 저장된 핀 전체를 여행 구간과 무관하게 표시한다.
- 도장은 국가당 하나만 생성하며 방문 횟수와 무관하다.
- 도장의 단위는 국가이되, 도장 표면에 표기하는 지명은 실제로 방문한 도시로 한다.

**데이터**
- 국가 도장 데이터는 국가 코드, 국가명, 해당 국가의 핀 수, 해당 국가에서 방문한 도시명 목록과 도시별 핀 수를 저장한다.

### 3.3 여행 계속하기
여행자는 홈 화면 상단의 여행 계속하기 진입점을 통해 진행 중인 여정에 이어서 촬영을 시작한다. NFC 태그가 없거나 태그 인식에 실패한 상황에서도 이 경로로 기록을 이어갈 수 있다. 이 기능은 촬영 흐름 진입에 한정하며, 이후의 촬영·저장 동작은 8번 영역과 동일하다.

**기능의 근거**

 NFC 미지원 기기 사용자, 태그를 소지하지 않은 상황, 태그 인식 실패는 실제로 발생한다. 태깅은 기록 정확도를 높이는 장치이지 기록의 필수 조건이 아니므로, 진행 중인 여정에 태깅 없이 이어 붙일 경로가 필요하다.

**개발 준비 슬롯**

**선행조건**
- 여행자는 로그인한 상태이다.
- 여행자는 카메라 권한을 허용한 상태이다.

**트리거**
- 여행자가 홈 화면 상단의 여행 계속하기를 선택한다.
- NFC 태그 인식에 실패한 뒤 여행자가 홈으로 이동해 여행 계속하기를 선택한다.

**동작**
- 서비스는 진행 중인 여정을 대상으로 NFC 태그 식별자 없이 새 태깅 세션을 생성한다.
- 서비스는 8.1 NFC 태깅 후 사진 촬영과 동일한 촬영 화면을 연다.

**결과**
- 여행자는 태깅 없이 촬영과 핀 저장 흐름을 진행한다.
- 저장된 핀은 진행 중인 여정에 포함되며 시작 유형이 수동으로 기록된다.
- 서비스는 여행 계속하기 선택 이벤트를 기록한다.

**예외**
- 카메라 권한이 없으면 1.3 권한 거부·미지원 안내로 이동한다.
- 진행 중인 여정이 없으면 새 여정을 생성한 뒤 촬영 화면을 연다.

**표시**
- 홈 화면 상단의 나의 여행 기록 제목 우측에 여행 계속하기 진입점을 표시한다.

**권한 & 접근**
- 서비스는 사진 촬영을 위해 카메라 권한을, 좌표 저장을 위해 위치 권한을 요청한다.

**비즈니스 규칙**
- 여행 계속하기로 시작한 세션도 NFC 태깅 세션과 동일한 핀 데이터 구조로 저장한다.
- 여행 계속하기로 생성한 세션은 7.4 제품별 태깅 횟수 집계에 포함하지 않는다.
- 진행 중인 여정 판별 기준은 3.1과 동일하게 여정 상태가 진행 중인 구간으로 한다.

**데이터**
- 태깅 세션에는 세션 식별자, 시작 유형(NFC 또는 수동), NFC 태그 식별자, 여행 구간 식별자, 시작 시각을 저장한다.

## 4 여행 구간 구성 및 관리
여행자는 여러 개의 핀 기록을 하나의 여행 구간으로 묶어 회고와 관리의 단위로 사용한다. 이 영역은 종료된 여정의 구간 목록과 요약 확인, 구간 이름·기간·포토북 수록 범위의 편집을 포함하며, 구간의 생성과 종료는 각각 8.1 태깅·5.1.2 수동 핀 입력과 3.1 홈에서 다루므로 포함하지 않는다. **[v3.5 변경]**
- 여정은 첫 태깅 시 자동으로 생성되며, 여행자는 홈에서 여정을 종료할 수 있다.
- 여행자는 종료된 여정의 이름, 기간, 포함된 핀 수와 사진 수를 확인할 수 있다. **[v3.5 변경]**
- 여행자는 구간에 포함된 핀 기록을 포토북 수록 대상에서 제외하거나 다시 포함할 수 있다. **[v3.5 변경]**
- 여행자는 좌표가 없는 핀을 구간의 핀 목록에서 확인할 수 있다.

### 4.1 여행 구간 목록·요약
여행자는 종료된 여정의 여행 구간 관리 화면에서 구간의 요약 지표(수록 핀 수, 연결된 사진 수, 여행 기간)와 포함된 핀 기록 목록을 확인한다. 이 기능은 구간 요약과 핀 목록 조회에 한정하며, 구간 이름·기간·수록 범위의 편집은 4.2에서 다룬다. **[v3.5 변경]**

**기능의 근거**

 핀이 쌓일수록 개별 핀만으로는 여행 전체의 규모를 파악하기 어렵다. 구간 단위 요약은 여행 하나가 어느 정도의 기록으로 남았는지 확인시키고, 포토북에 어떤 핀이 실릴지 점검할 근거가 된다.

**성공 기준**

 여행 구간 관리 화면 방문율과 구간 편집 진입률을 측정한다.

**개발 준비 슬롯**

**선행조건**
- 여행자에게 종료된 여정이 하나 이상 있다. **[v3.5 변경]**

**트리거**
- 여행자가 6.1 포토북 아카이빙 목록의 여행별 포토북 항목에서 여행 구간 관리를 선택한다. **[v3.5 변경]**- 여행자가 6.2 여정별 포토북 상단의 여행 구간 관리를 선택한다. **[v3.5 변경]**

**동작**
- 서비스는 구간에 포함된 핀 수, 연결된 사진 수, 여행 기간을 집계해 요약 영역에 표시한다.
- 서비스는 포함된 핀 기록을 촬영 시각 오름차순으로 나열한다.
- 서비스는 각 핀의 포토북 수록 여부를 함께 표시한다. **[v3.5 신설]**- 여행자가 특정 핀을 선택하면 서비스는 5.2 핀 상세로 이동한다.
- 여행자가 구간 편집을 선택하면 서비스는 4.2 구간 상세 및 편집으로 이동한다.

**결과**
- 여행자는 구간 단위의 누적 규모와 포함된 핀 목록을 확인한다.
- 서비스는 구간 목록 조회 이벤트를 기록한다.

**예외**
- 구간에 포함된 핀이 없으면 핀이 없다는 빈 상태를 표시한다.
- 좌표가 없는 핀은 지도와 동선에서 제외되지만 이 목록에는 위치 정보 없음 상태로 표시한다.
- 진행 중인 여정으로는 이 화면에 진입할 수 없다. **[v3.5 신설]**

**표시**
- 요약 영역은 수록 핀 수, 연결된 사진 수, 여행 기간을 나란히 표시한다.
- 핀 목록의 각 항목은 대표 사진, 장소명, 촬영일, 사진 수, 포토북 수록 여부를 표시한다. **[v3.5 변경]**- 포토북 수록에서 제외된 핀 항목에는 포토북 미수록 표기를 함께 표시한다. **[v3.5 신설]**- 좌표가 없는 핀 항목에는 위치 정보 없음 표기를 함께 표시한다.
- 집계를 불러오는 동안 처리 중 상태를 표시한다.

**권한 & 접근**
- 여행자는 자신의 핀으로 구성된 구간만 조회할 수 있다.

**비즈니스 규칙**
- 여행 구간 관리는 종료된 여정에 대해서만 제공한다. **[v3.5 신설]**- 구간의 기간은 사용자가 직접 지정하지 않은 경우 포함된 핀 기록의 시각 범위로 계산한다.
- 핀 목록의 정렬 기준은 핀의 촬영 시각이다.
- 요약 지표의 핀 수와 사진 수는 포토북 수록 대상 핀을 기준으로 집계한다. **[v3.5 신설]**

**데이터**
- 구간 요약에는 구간 식별자, 구간 이름, 상태, 시작·종료 시각, 핀 수, 사진 수를 조회한다.
- 핀 목록 항목에는 핀 식별자, 장소명, 촬영 시각, 사진 수, 좌표 보유 여부, 포토북 수록 여부를 조회한다. **[v3.5 변경]**

### 4.2 구간 상세 및 편집
여행자는 종료된 여행 구간의 이름·기간·포토북 수록 범위를 수정한다. 이 기능은 구간 이름 입력, 기간 지정, 수록 핀 범위 지정과 개별 핀의 수록·제외를 포함하며, 구간의 신규 생성과 종료, 핀 데이터의 삭제는 포함하지 않는다. **[v3.5 변경]**

**기능의 근거**

 자동으로 묶인 구간이 사용자가 인식하는 여행 단위와 어긋날 수 있다. 어떤 핀을 포토북에 실을지 사용자가 직접 조정할 수 있어야 결과물이 자신의 여행과 맞는다. 다만 제외는 기록의 삭제가 아니라 수록 대상에서 빼는 것이므로, 핀과 사진은 그대로 보존해야 한다.

**성공 기준**

 구간 편집 저장 완료율과 편집 후 포토북 재생성 발생률을 측정한다.

**개발 준비 슬롯**

**선행조건**
- 여행자에게 종료된 여행 구간이 있고 그 구간에 핀이 하나 이상 있다. **[v3.5 변경]**

**트리거**
- 여행자가 4.1에서 여행 구간의 편집을 선택한다.

**동작**
- 여행자는 구간 이름을 입력한다.
- 서비스는 이름 입력란에 자동 생성된 도시명 나열을 안내 문구로 표시하고, 여행자가 입력하지 않으면 그 값을 그대로 사용한다. **[v3.5 신설]**- 서비스는 수록 대상 핀 중 가장 이른 태깅 시각을 시작일로, 가장 늦은 태깅 시각을 종료일로 자동 채운다. **[v3.5 신설]**- 여행자는 캘린더에서 시작일과 종료일을 직접 선택해 자동으로 채워진 값을 덮어쓸 수 있다. **[v3.5 신설]**- 여행자는 수록 핀 범위의 시작 핀과 종료 핀을 지정해 포토북에 실을 핀을 한 번에 정한다.
- 여행자는 핀 목록에서 개별 핀의 수록 여부를 각각 켜고 끌 수 있다.
- 서비스는 수록 대상 핀의 수와 연결된 사진 수를 실시간으로 재집계해 화면 하단에 표시한다.
- 서비스는 저장 시 구간 이름, 기간, 핀별 수록 여부를 갱신한다.
- 서비스는 저장 후 6.1.1에 따라 해당 여정의 포토북을 다시 생성한다. **[v3.5 신설]**

**결과**
- 서비스는 갱신된 구간 정보와 핀별 수록 여부를 저장한다.
- 제외한 핀의 핀 데이터, 사진, 기록 맥락은 그대로 보존되며 지도·핀 상세·전체 사진 보기에서 계속 조회된다. **[v3.5 신설]**- 서비스는 구간 편집 이벤트를 분석용으로 기록한다.

**예외**
- 수록 핀을 하나도 남기지 않으면 저장할 수 없게 하고 안내를 표시한다. **[v3.5 변경]**- 수록 핀 범위의 종료 핀이 시작 핀보다 앞서면 저장을 막고 안내를 표시한다.
- 여행자가 지정한 종료일이 시작일보다 앞서면 저장을 막고 안내를 표시한다. **[v3.5 신설]**- 여행자가 지정한 기간 밖에 있는 핀도 수록 대상에서 자동으로 빠지지 않으며, 수록 여부는 핀별 선택으로만 결정한다. **[v3.5 신설]**- 동시 수정이 발생하면 최신 저장 상태를 확인하도록 안내한다.

**표시**
- 화면은 구간 이름 입력란, 여행 기간 입력란, 수록 핀 범위 지정란, 핀 목록을 순서대로 표시한다.
- 여행 기간 입력란은 자동으로 채워진 시작일·종료일을 표시하고, 각각을 선택하면 캘린더를 열어 직접 지정할 수 있게 한다. **[v3.5 신설]**- 여행 기간 입력란에는 자동 계산된 값을 다시 적용하는 초기화 진입점을 함께 표시한다. **[v3.5 신설]**- 핀 목록의 각 항목은 핀 번호, 장소명, 촬영 시각, 사진 수와 수록 여부 선택 상태를 표시한다.
- 핀을 제외할 때는 기록이 삭제되지 않고 포토북에만 실리지 않는다는 안내를 표시한다. **[v3.5 신설]**- 화면 하단은 수록 핀 수와 연결된 사진 수를 표시한다.
- 저장 성공 또는 실패 결과를 사용자에게 안내한다.

**권한 & 접근**
- 여행자는 자신의 핀으로 구성된 여행 구간만 편집할 수 있다.

**비즈니스 규칙**
- 여행 구간은 하나 이상의 수록 핀을 포함해야 한다.
- 구간의 신규 생성은 8.1 태깅과 5.1.2 핀 수동 입력으로만 이루어지며 이 화면에서는 생성하지 않는다. **[v3.5 변경]**- 핀을 수록 대상에서 제외해도 핀·사진·기록 맥락 데이터는 삭제하지 않는다. **[v3.5 신설]**- 제외한 핀은 여전히 해당 여정에 속한 핀으로 저장되며, 다른 여정으로 이동하거나 어느 여정에도 속하지 않는 상태가 되지 않는다. **[v3.5 신설]**- 제외의 효과는 6.2 여정별 포토북의 수록 대상에서 빠지는 것으로 한정하며, 5.1 지도 뷰·5.2 핀 상세·5.3 핀 전체 사진 보기·3.2 여권 도장 집계에는 그대로 반영된다. **[v3.5 신설]**- 제외한 핀은 언제든 다시 수록 대상으로 되돌릴 수 있다. **[v3.5 신설]**- 수록 핀 범위 지정과 개별 핀 선택이 충돌하면 나중에 수행한 조작을 우선한다.
- 시작일·종료일은 사용자가 직접 지정하면 그 값을 우선하고, 지정하지 않으면 수록 핀의 시각 범위를 사용한다. **[v3.5 변경]**

**데이터**
- 여행 구간은 여행자 식별자, 사용자 입력 이름, 자동 생성 이름, 기간 시작·종료 시각, 기간 수동 지정 여부, 핀 목록, 사진 수, 상태(진행 중·종료됨), 종료 시각을 저장한다. **[v3.5 변경]**- 구간-핀 연결은 구간 식별자, 핀 식별자, 포토북 수록 여부, 수록 여부 변경 시각으로 저장한다. **[v3.5 변경]**

## 5 여행 기록 탐색
여행자는 저장된 핀 기록과 여행 동선을 지도에서 탐색하고, 핀 상세에서 취향 기반 추천 사진과 촬영 맥락을 확인한다. 이 영역은 지도 뷰, 촬영량 기반 동선 표시, 핀 수동 입력, 핀 상세와 추천, 핀 전체 사진 보기, 주변 사진 추가를 포함하며, 포토북 생성과 열람은 6번 영역에서 다룬다. **[v3.5 변경]**
- 여행자는 지도 진입 직후의 기본 배율에서 태깅 위치의 핀과 사진 미리보기를 확인할 수 있다.
- 여행자는 지도에서 위치를 직접 지정하고 사진을 업로드해 핀을 수동으로 추가할 수 있다. **[v3.5 변경]**
- 여행자는 사진 촬영량에 따라 갈색 농도가 다른 시간순 동선을 확인할 수 있다.
- 핀 상세에서 추천 사진, 맥락, 시각, 장소 정보를 확인할 수 있다.
- 여행자는 핀에 연결된 전체 사진을 태깅 세션 단위로 확인하고 사진을 추가하거나 삭제할 수 있다. **[v3.5 변경]**
- 여행자는 핀 반경 1km 이내에서 촬영한 사진을 선택해 해당 핀에 추가할 수 있다.

### 5.1 지도 뷰
여행자는 태깅으로 만든 핀 기록과 여행 동선을 지도에서 탐색하고, 핀을 선택해 상세 기록으로 이동한다. 지도는 축소 상태에서 방문 국가를 브랜드 컬러·패턴으로 구별해 표시하고, 확대 상태에서 촬영량에 따른 갈색 동선을 표시한다. 이 기능은 지도 표시와 핀 선택, 여행 구간 필터에 한정하며, 포토북 생성은 포함하지 않는다.

**기능의 근거**

 태깅의 결과와 여행 중 사진을 많이 남긴 장소가 눈에 보여야 사용자는 기록의 가치를 확인하고 여행을 회고할 수 있다. 지도는 핀이 실제로 쌓이고 있다는 사실을 가장 직접적으로 보여주는 뷰다.

**성공 기준**

 지도 재방문율과 핀 상세 열람률을 측정한다.

**개발 준비 슬롯**

**선행조건**
- 여행자에게 좌표가 있는 핀 기록이 하나 이상 있다.

**트리거**
- 여행자가 하단 내비게이션에서 지도를 선택한다.
- 여행자가 3.2 가상 여권에서 국가 도장을 선택한다.

**동작**
- 서비스는 여행 선택 드롭다운에서 선택된 여행 구간의 핀만 지도에 표시한다.
- 서비스는 지도 진입 시 선택된 여행 구간의 핀이 화면에 모두 보이는 줌 레벨로 지도를 맞춘다.
- 서비스는 축소된 줌 레벨에서 방문한 국가를 브랜드 컬러·패턴으로 채색해 방문하지 않은 국가와 구별한다.
- 서비스는 확대된 줌 레벨에서 5.1.1 촬영량 기반 갈색 동선을 표시한다. 다만 3.2 국가 도장으로 진입한 국가 필터 상태에서는 동선을 표시하지 않는다.
- 여행자가 지도 핀을 선택하면 서비스는 지도 하단에 해당 핀의 요약 카드를 표시한다.
- 여행자가 요약 카드의 핀 상세 보기를 선택하면 서비스는 5.2 핀 상세로 이동한다.
- 여행자가 우측 상단의 핀 수동 입력 진입점을 선택하면 서비스는 5.1.2의 위치 지정 화면(5.1 B)으로 이동한다. **[v3.5 신설]**

**결과**
- 여행자는 여행 구간별 핀과 동선을 지도에서 확인한다.
- 서비스는 지도 조회 이벤트, 여행 구간 필터 변경 이벤트, 핀 선택 이벤트를 기록한다.

**예외**
- 좌표가 없는 핀은 지도와 동선에서 제외하고, 4.1 여행 구간 관리의 포함된 핀 목록에 위치 정보 없음 상태로 표시한다.
- 표시할 핀이 하나도 없으면 지도를 기본 위치로 두고 기록이 없다는 빈 상태를 표시한다.

**표시**
- 지도 상단에는 여행 선택 드롭다운을 표시한다.
- 지도 우측 상단에는 5.1.2 핀 수동 입력 진입점을 표시하며, 선택하면 위치 지정 화면(5.1 B)으로 이동한다. **[v3.5 변경]**- 지도 진입 직후의 기본 줌 레벨에서도 핀은 항상 보이게 표시한다.
- 지도 핀에는 해당 핀의 추천 사진 미리보기를 표시한다.
- 핀 요약 카드는 대표 사진, 장소명, 주소, 촬영 일시, 한 줄 맥락, 핀 상세 보기 진입점을 표시한다.
- 지도와 핀을 불러오는 동안 처리 중 상태를 표시한다.

**권한 & 접근**
- 이 기능은 여행자의 저장된 핀 기록만 표시한다.

**비즈니스 규칙**
- 여행 선택 드롭다운의 기본값은 진행 중인 여정이며, 진행 중인 여정이 없으면 가장 최근 여정이다.
- 지도 진입 시 기본 줌 레벨은 선택된 여행 구간의 핀 좌표 전체를 포함하는 범위로 자동 계산하며, 국가 채색만 보이고 핀이 보이지 않는 배율로 진입하지 않는다.
- 핀이 하나뿐이면 해당 핀을 중심으로 도시 단위 배율로 진입한다.
- 국가 채색의 기준은 해당 국가에서 촬영한 사진이 1장 이상 존재하는 것이다.
- 국가 채색과 갈색 동선은 동시에 표시하지 않으며 줌 레벨로 전환한다.
- 3.2 가상 여권의 국가 도장으로 진입한 경우를 국가 필터 상태로 보며, 이 상태에서는 해당 국가에 저장된 핀만 여행 구간과 무관하게 표시하고 동선은 표시하지 않는다.
- 국가 필터 상태의 기본 줌 레벨은 해당 국가의 핀 좌표 전체를 포함하는 범위로 자동 계산한다.
- 국가 필터 상태에서 여행 선택 드롭다운을 변경하면 국가 필터를 해제하고 일반 지도 뷰로 되돌아간다.

**데이터**
- 지도는 핀의 좌표, 촬영 시각, 추천 사진, 맥락, 장소 정보를 조회한다.
- 국가 채색에는 핀 좌표에서 도출한 국가 코드 목록을 조회한다.

#### 5.1.1 촬영량 기반 갈색 동선 표시
여행자는 지도에서 핀들이 시간순으로 연결된 동선을 보며, 사진을 많이 찍은 구간은 진한 갈색으로, 상대적으로 적게 찍은 구간은 옅은 갈색으로 확인한다. 이 동작은 지도 뷰에서의 동선 렌더링과 색상 계산에 한정하며, 핀 상세 이동은 포함하지 않는다.

**기능의 근거**

 여행 동선을 선으로만 그리면 어디에 오래 머물렀는지가 드러나지 않는다. 촬영량을 색 농도로 환산하면 사용자가 인상 깊게 느낀 구간이 지도 위에서 즉시 구별되고, 이는 지도를 단순 위치 기록에서 회고 도구로 바꾼다.

**성공 기준**

 동선이 표시된 지도의 체류 시간과 동선 구간을 통한 핀 상세 진입률을 측정한다.

**개발 준비 슬롯**

**선행조건**
- 여행자에게 좌표가 있는 핀 기록이 둘 이상 있다.
- 각 핀은 연결된 사진 수 정보를 보유한다.

**트리거**
- 여행자가 지도 뷰에서 동선 표시 임계 줌 레벨 이상으로 확대한다.

**동작**
- 서비스는 좌표가 있는 핀을 촬영 시각 오름차순으로 정렬한다.
- 서비스는 시간상 인접한 두 핀을 하나의 선분으로 연결하고, 선분 하나를 구간 하나로 정의한다.
- 서비스는 각 구간의 가중치를 시작 핀과 종료 핀에 연결된 사진 수의 평균값으로 산출한다.
- 서비스는 선택된 여행 구간 전체의 구간 가중치를 최소값 0, 최대값 1로 정규화한다.
- 서비스는 정규화 값에 비례해 옅은 갈색 토큰과 진한 갈색 토큰 사이를 연속 보간한 색상을 각 구간에 적용한다.

**결과**
- 여행자는 지도에서 어느 구간에서 사진을 많이 찍었는지 한눈에 확인한다.
- 서비스는 동선 렌더링 이벤트, 줌 레벨 전환 이벤트, 구간별 가중치를 기록한다.

**예외**
- 좌표가 있는 핀이 1개 이하이면 동선을 그리지 않고 해당 핀만 표시한다.
- 3.2 국가 도장으로 진입한 국가 필터 상태에서는 줌 레벨과 무관하게 동선을 그리지 않는다.
- 모든 구간의 가중치가 동일하면 전 구간을 옅은 갈색과 진한 갈색의 중간 농도로 표시한다.
- 좌표가 없는 핀은 동선 계산에서 제외하고, 4.1 여행 구간 관리의 포함된 핀 목록에 위치 정보 없음 상태로 표시한다.

**표시**
- 동선은 핀 사이를 이어 그리며 구간별로 갈색 농도를 다르게 표시한다.
- 농도는 단계 구분 없이 연속 그라데이션으로 표시한다.
- 확대·축소를 반복해도 구간 사이의 농도 상대 관계는 유지한다.
- 동선 색상 계산이 끝나기 전에는 동선 없이 핀만 먼저 표시한다.

**권한 & 접근**
- 여행자는 자신의 여행 핀으로 구성된 동선만 조회할 수 있다.

**비즈니스 규칙**
- 동선의 순서는 핀의 촬영 시각을 기준으로 정렬한다.
- 구간 가중치는 시작 핀과 종료 핀의 사진 수 평균으로 산출한다.
- 정규화 범위는 현재 지도에 표시 중인 여행 구간 전체를 기준으로 하며, 여행 구간을 바꾸면 다시 계산한다.
- 갈색의 시작·종료 색상은 디자인 시스템의 동선 색상 토큰(옅은 갈색 토큰, 진한 갈색 토큰)을 사용한다.
- 동선 표시 임계 줌 레벨 이하에서는 동선을 그리지 않고 국가 채색만 표시한다. 임계 줌 레벨 값은 지도 라이브러리 확정 후 확정한다.

**데이터**
- 동선 렌더링에는 핀 식별자, 위도, 경도, 촬영 시각, 핀별 연결 사진 수를 조회한다.
- 구간 정보에는 구간 식별자, 시작 핀 식별자, 종료 핀 식별자, 구간 가중치, 정규화 값을 저장한다.

#### 5.1.2 지도에서 핀 수동 입력 **[v3.5 전면 개정]**
여행자는 지도 뷰 우측 상단의 핀 수동 입력 진입점을 통해 NFC 태깅 없이 핀을 직접 만든다. 핀 생성은 두 단계로 진행한다. 위치 지정 화면(5.1 B)에서 지도를 드래그해 핀을 놓을 지점을 정하고, 정보 입력 화면(5.1 C)에서 장소 이름·날짜·시각·텍스트 메모를 입력하고 사진과 음성 메모를 추가한 뒤 핀을 생성한다. 이 기능은 촬영 흐름을 사용하지 않으며, 카메라로 즉시 촬영하는 경로는 8.1에서 다룬다.

**기능의 근거**

 태그를 소지하지 않았거나 NFC 인식에 실패한 상황, 이미 지나온 장소를 나중에 기록하려는 상황에서도 핀을 남길 수 있어야 한다. 현재 위치에 묶이지 않고 지도에서 지점을 직접 지정하게 하면 과거에 다녀온 장소도 정확한 좌표로 기록할 수 있고, 위치 권한이 없는 사용자도 좌표가 있는 핀을 만들 수 있다.

**성공 기준**

 수동 핀 생성 진입 대비 생성 완료율과, 위치 지정 화면에서 정보 입력 화면으로의 이탈률을 측정한다.

**개발 준비 슬롯**

**선행조건**
- 여행자는 로그인한 상태이다.

**트리거**
- 여행자가 5.1 지도 뷰 우측 상단의 핀 수동 입력 진입점을 선택한다.

**동작**
- 서비스는 위치 지정 화면(5.1 B)을 열고 지도 중앙에 핀 표시자를 고정해 표시한다.
- 여행자가 지도를 드래그하면 서비스는 지도만 움직이고 핀 표시자는 화면 중앙에 고정한 채 중앙 지점의 좌표를 실시간으로 갱신한다.
- 서비스는 갱신된 좌표의 장소명과 주소를 조회해 화면에 표시한다.
- 여행자가 현재 위치로 이동을 선택하면 서비스는 기기의 현재 좌표로 지도를 이동시킨다.
- 여행자가 이 위치로 지정을 선택하면 서비스는 화면 중앙 지점의 좌표를 해당 핀의 위치로 확정하고 정보 입력 화면(5.1 C)으로 이동한다.
- 서비스는 정보 입력 화면에 확정된 좌표의 장소명을 장소 이름 입력란의 초기값으로 채운다.
- 여행자는 장소 이름, 날짜, 시각, 텍스트 메모를 입력한다.
- 여행자는 갤러리에서 사진을 선택해 여러 장 업로드한다.
- 서비스는 업로드된 사진 중 촬영 시각이 가장 이른 사진의 촬영 시각을 읽어 날짜와 시각 입력란에 자동으로 채운다.
- 여행자는 자동으로 채워진 날짜와 시각을 직접 수정할 수 있다.
- 여행자는 음성 메모 남기기를 선택해 음성을 녹음한다.
- 여행자가 핀 추가하기를 선택하면 서비스는 입력된 좌표·장소 이름·시각·텍스트 메모·사진·음성 메모로 핀을 생성하고 5.1 지도 뷰로 돌아간다.
- 서비스는 핀 생성 완료를 트리거로 5.2.1 핀별 사진 추천의 추천 생성을 시작한다.

**결과**
- 새 핀이 지도에 표시되고 진행 중인 여정에 포함된다.
- 서비스는 수동 핀 위치 지정 이벤트와 핀 생성 완료 이벤트를 기록한다.

**예외**
- 사진을 한 장도 업로드하지 않으면 날짜와 시각을 자동으로 채우지 않고, 여행자가 직접 입력한 값을 사용한다.
- 업로드한 사진에서 촬영 시각을 읽을 수 없으면 자동 입력을 건너뛰고 현재 시각을 초기값으로 채운다.
- 사진을 한 장도 업로드하지 않아도 핀은 생성할 수 있으며, 이 경우 추천 사진은 생성하지 않는다.
- 위치 권한이 거부되면 현재 위치로 이동을 비활성으로 표시하고, 지도 드래그로만 위치를 지정하게 한다.
- 마이크 권한이 거부되면 음성 메모 진입점을 비활성으로 표시하고 텍스트 메모만 제공한다.
- 장소명 조회에 실패하면 좌표만 확정하고 장소 이름 입력란을 비워 둔다.
- 여행자가 위치 지정 화면이나 정보 입력 화면에서 이탈하면 핀을 생성하지 않는다.

**표시**
- 위치 지정 화면은 지도, 화면 중앙 고정 핀 표시자, 현재 지점의 장소명과 주소, 현재 위치로 이동 진입점, 이 위치로 지정 버튼을 표시한다.
- 지도를 드래그하는 동안 핀 표시자에 이동 중임을 나타내는 상태를 표시한다.
- 정보 입력 화면은 확정된 위치의 지도 미리보기, 장소 이름 입력란, 날짜 입력란, 시각 입력란, 텍스트 메모 입력란, 사진 업로드 영역, 음성 메모 남기기 진입점, 핀 추가하기 버튼을 순서대로 표시한다.
- 날짜와 시각이 업로드 사진에서 자동으로 채워진 경우 사진 기준으로 입력되었다는 안내를 함께 표시한다.
- 사진 업로드 영역은 선택한 사진의 미리보기와 장수를 표시한다.
- 핀을 생성하는 동안 처리 중 상태를 표시한다.

**권한 & 접근**
- 서비스는 사진 업로드를 위해 사진 라이브러리 접근 권한을, 현재 위치 이동을 위해 위치 권한을, 음성 메모를 위해 마이크 권한을 사용한다.
- 위치 권한이 없어도 지도 드래그로 좌표를 지정할 수 있으므로 핀 생성 자체는 차단하지 않는다.

**비즈니스 규칙**
- 수동으로 생성한 핀도 NFC 태깅 핀과 동일한 데이터 구조로 저장한다.
- 핀의 좌표는 위치 지정 화면에서 이 위치로 지정을 선택한 시점의 화면 중앙 좌표로 확정한다.
- 핀의 시각은 업로드한 사진 중 촬영 시각이 가장 이른 사진을 기준으로 자동 입력하며, 여행자가 수정하면 수정한 값을 우선한다.
- 수동으로 생성한 핀은 진행 중인 여정에 포함하며, 진행 중인 여정이 없으면 새 여정을 생성해 진행 중 상태로 둔다.
- 수동으로 생성한 세션은 7.4 제품별 태깅 횟수 집계에 포함하지 않는다.
- 수동 입력으로 남긴 텍스트 메모와 음성 메모도 핀당 각각 1개로 제한한다.

**데이터**
- 태깅 세션에는 세션 식별자, 시작 유형(NFC 또는 수동), NFC 태그 식별자, 시작 시각, 좌표를 저장한다.
- 핀에는 좌표, 좌표 확정 방식(현재 위치 또는 지도 지정), 장소 이름, 시각, 시각 입력 방식(사진 자동 또는 직접 입력), 텍스트 기록, 음성 메모 식별자를 저장한다.
- 업로드 사진에는 사진 식별자, 핀 식별자, 촬영 시각, 등록 경로(업로드)를 저장한다.

### 5.2 핀 상세
여행자는 지도 또는 핀 목록에서 핀을 선택해 해당 순간의 대표 사진과 촬영 맥락, 시각, 장소 정보를 한 화면에서 확인하고, 취향 프로파일에 맞춘 대표 사진 3장 추천을 함께 본다. 이 기능은 핀 하나의 상세 기록 열람과 텍스트 기록 수정, 진입점 제공에 한정하며, 추천 생성·수정·재추천과 음성 재생은 하위 기능에서 다룬다. **[v3.5 변경]**

**기능의 근거**

 여행자는 여러 유사 사진 속에서 자기 기준의 대표 사진을 다시 골라야 하는 재선별 부담을 겪는다. 핀 상세에서 대표 사진과 맥락을 함께 보여주고 취향 기반 추천을 제공하면, 촬영 순간의 기록을 잃지 않으면서도 회고 부담을 줄일 수 있다. 텍스트 기록은 촬영 직후 급하게 적은 경우가 많아 나중에 고칠 수 있어야 하지만, 그 순간의 목소리인 음성은 고쳐 쓰는 대상이 아니다.

**성공 기준**

 핀 상세 열람률과 추천 사진 채택률을 측정한다.

**개발 준비 슬롯**

**선행조건**
- 여행자에게 저장된 핀 기록이 있다.
- 여행자는 취향 프로파일을 생성했다.

**트리거**
- 여행자가 5.1 지도 뷰의 핀 요약 카드에서 핀 상세 보기를 선택한다.
- 여행자가 4.1 여행 구간 관리의 핀 목록에서 핀을 선택한다.
- 여행자가 6.2 여정별 포토북에서 자세히를 선택한다. **[v3.5 변경]**

**동작**
- 서비스는 선택한 핀의 위치를 지도 미리보기로 표시한다.
- 서비스는 장소명, 주소, 촬영 일시를 표시한다.
- 서비스는 저장된 텍스트 기록과 음성 메모를 기록 맥락 영역에 표시한다.
- 여행자가 텍스트 기록의 수정을 선택하면 서비스는 입력란을 열어 기존 내용을 편집하게 한다. **[v3.5 신설]**- 서비스는 수정된 텍스트 기록을 저장하고 기존 기록을 덮어쓴다. **[v3.5 신설]**- 서비스는 촬영 흐름에서 녹음된 음성 메모에는 수정·재녹음 진입점을 제공하지 않는다. **[v3.5 신설]**- 서비스는 5.2.1에서 생성된 추천 사진 3장을 표시한다.
- 여행자는 추천 사진 영역 우측 상단의 사진 추가 진입점을 선택해 5.4 주변 사진 추가로 이동한다.
- 여행자는 화면 하단의 이 핀의 모든 사진 보기 또는 재추천 받기를 선택해 이동한다.

**결과**
- 여행자는 핀의 대표 사진, 맥락, 시각, 장소를 확인한다.
- 서비스는 핀 상세 열람 이벤트와 텍스트 기록 수정 이벤트를 기록한다. **[v3.5 변경]**

**예외**
- 텍스트 기록과 음성 메모가 모두 없는 핀에는 기록 맥락 영역을 표시하지 않는다.
- 좌표가 없는 핀에는 지도 미리보기 대신 위치 정보가 없다는 표기를 표시한다.
- 핀에 사진이 1장뿐이면 해당 사진만 대표로 표시한다.
- 텍스트 기록을 비운 채 저장하면 해당 핀의 텍스트 기록을 삭제한 것으로 처리한다. **[v3.5 신설]**

**표시**
- 핀 상세는 지도 미리보기, 장소명, 주소·촬영 일시, 기록 맥락, 추천 사진 3장을 순서대로 표시한다.
- 기록 맥락 영역의 텍스트 기록 우측에는 수정 진입점을 표시한다. **[v3.5 신설]**- 음성 메모에는 재생 컨트롤만 표시하고 수정·삭제 진입점은 표시하지 않는다. **[v3.5 신설]**- 추천 결과는 점수나 등급을 노출하지 않고 대표 사진 3장을 묶음으로 표시한다.
- 추천 사진 제목 우측에는 사진 추가 진입점을 더하기 아이콘으로 표시한다.
- 화면 하단에는 이 핀의 모든 사진 보기와 재추천 받기 진입점을 표시한다.
- 추천 결과를 불러오는 동안 처리 중 상태를 표시한다.

**권한 & 접근**
- 여행자는 본인의 핀 기록만 조회하고 수정할 수 있다.

**비즈니스 규칙**
- 지도 미리보기의 위치는 저장된 GPS 좌표를 기준으로 한다.
- 추천은 범용 미학 평가가 아닌 사용자 취향 프로파일을 기준으로 한다.
- 핀 하나에는 텍스트 기록 1개와 음성 메모 1개만 저장한다. **[v3.5 신설]**- 텍스트 기록은 저장 이후에도 언제든 수정할 수 있으며 수정 횟수에 제한을 두지 않는다. **[v3.5 신설]**- 8.1 촬영 흐름에서 녹음한 음성 메모는 저장 이후 수정하거나 다시 녹음할 수 없다. **[v3.5 신설]**

**데이터**
- 핀 상세는 핀 식별자로 사진, 텍스트 기록, 음성 메모, 촬영 시각, 좌표, 장소 데이터를 조회한다.
- 텍스트 기록에는 마지막 수정 시각을 함께 저장한다. **[v3.5 신설]**

#### 5.2.1 핀별 사진 추천
서비스는 각 핀에 연결된 사진에서 유사 사진을 줄이고 취향 프로파일에 따라 스코어링해 대표 사진 3장을 선정한다. 핀을 처음 열 때는 주변 1km 이내에서 태깅 없이 촬영한 사진을 추가로 업로드하도록 안내하고, 업로드가 이루어지면 같은 기준으로 다시 선정한다. 사진 보정이나 미학 점수 공개는 포함하지 않는다.

**개발 준비 슬롯**

**선행조건**
- 핀에는 추천할 사진이 하나 이상 존재한다.
- 여행자는 취향 프로파일을 생성했다.

**트리거**
- 여행자가 핀 저장을 완료하면 서비스는 해당 핀의 추천 결과를 생성한다.
- 여행자가 핀 상세를 열면 서비스는 생성된 추천 결과를 표시한다.
- 여행자가 5.3에서 사진을 추가하거나 삭제하면 서비스는 추천을 다시 선정한다. **[v3.5 신설]**

**동작**
- 서비스는 핀에 연결된 사진에서 촬영 시각 근접도와 이미지 유사도를 이용해 유사 사진을 줄인다.
- 서비스는 남은 사진을 취향 프로파일 가중치로 스코어링해 대표 사진 3장을 선정한다.
- 서비스는 여행자가 해당 핀을 처음 열 때 주변 사진 업로드를 유도하는 문구를 표시한다.
- 여행자는 유도 문구에서 주변 사진을 선택해 업로드하거나 건너뛸 수 있다.
- 업로드가 이루어지면 서비스는 촬영 사진과 업로드 사진을 합친 뒤 동일한 기준으로 대표 사진 3장을 다시 선정한다.

**결과**
- 서비스는 핀별 대표 사진 3장을 제안한다.
- 서비스는 추천 생성 이벤트, 주변 사진 업로드 이벤트, 추천 재생성 이벤트를 기록한다.

**예외**
- 핀에 사진이 한 장이면 해당 사진을 대표 사진으로 제안하고 유사 사진 제거를 건너뛴다.
- 핀에 연결된 사진이 3장 미만이면 있는 사진을 순서대로 추천한다.
- 핀에 사진이 하나도 없으면 추천을 생성하지 않는다. **[v3.5 신설]**

**표시**
- 추천 결과는 점수나 등급을 노출하지 않고 대표 사진 3장을 묶음으로 표시한다.
- 핀을 처음 열 때는 해당 장소에서 더 촬영한 사진이 있는지 묻는 유도 문구와 사진 선택 진입점을 함께 표시한다.
- 추천을 생성하거나 재계산하는 동안 처리 중 상태를 표시한다.

**권한 & 접근**
- 이 기능은 본인이 저장한 핀 사진과 프로파일 데이터만 사용한다.

**비즈니스 규칙**
- 서비스는 보편적으로 좋은 사진을 판단하지 않고 사용자 취향 기준을 적용한다.
- 유사 사진 제거에는 촬영 시각 근접도와 이미지 유사도를 사용한다.
- 추천은 핀별로 3장을 기본으로 제안한다.
- 주변 사진 유도 문구는 해당 핀을 처음 열 때 1회 표시하며, 이후에는 5.2 핀 상세의 추천 사진 영역 우측 사진 추가 진입점과 5.3 핀 전체 사진 보기의 주변 사진 추가 진입점으로 상시 제공한다.

**데이터**
- 추천 결과에는 핀 식별자, 사진 식별자, 추천 순서, 추천 버전, 생성 시각을 저장한다.

#### 5.2.2 추천 사진 수정 반영
여행자는 핀별 추천 결과에서 사진을 추가하거나 제외해 최종 선별 결과를 조정한다. 수정 선택은 현재 핀의 결과를 바꾸고 이후 추천을 위한 취향 프로파일 보정 신호로 저장한다.※ 화면 미설계 — 디자인 필요

**개발 준비 슬롯**

**선행조건**
- 서비스가 핀별 추천 사진을 제시했다.

**트리거**
- 여행자가 추천 결과의 수정 동작을 선택한다.

**동작**
- 여행자는 추천 사진을 제외하거나 추천되지 않은 사진을 추가한다.
- 서비스는 수정 결과를 즉시 반영하고 선택 신호를 프로파일 보정에 누적한다.

**결과**
- 서비스는 수정된 핀별 선별 결과를 저장한다.
- 서비스는 추가·제외 신호를 취향 프로파일 갱신에 반영해 이후 추천 정확도를 높인다.

**예외**
- 여행자가 모든 추천 사진을 제외하면 서비스는 해당 핀에 대표 사진이 없음을 표시한다.

**표시**
- 추천 결과에서 사진별 추가와 제외 상태를 구분해 표시한다.

**권한 & 접근**
- 여행자는 본인의 추천 결과만 수정할 수 있다.

**비즈니스 규칙**
- 여행자의 추가·제외 선택은 범용 미학 평가가 아닌 개인 취향 보정 신호로 처리한다.
- 5.2.3 재추천과 달리 이 화면의 수정 선택만 취향 프로파일 보정에 반영한다. **[v3.5 신설]**

**데이터**
- 수정 이력에는 핀 식별자, 사진 식별자, 추가 또는 제외 유형, 처리 시각을 저장한다.

#### 5.2.3 추천 사진 재추천 요청(새로고침) **[v3.5 전면 개정]**
여행자는 핀 상세에서 재추천 받기를 선택해 같은 핀의 대표 사진 3장을 다시 선정받는다. 서비스는 해당 핀에 등록된 사진을 요청 시점의 취향 프로파일로 스코어링해 상위 10장을 후보로 추리고, 그중 3장을 무작위로 골라 결과를 교체한다. 이 동작은 기존 추천 결과를 새 추천으로 교체하는 범위에 한정하며, 개별 사진의 추가·제외는 5.2.2에서 다룬다.

**기능의 근거**

 추천 결과가 마음에 들지 않을 때 사진을 하나씩 바꾸는 것은 노동이 다시 발생하는 일이다. 묶음 단위로 다시 요청할 수 있어야 선별 자동화라는 약속이 유지된다. 상위 후보 안에서 무작위로 뽑는 방식은 취향 기준을 유지하면서도 매번 다른 조합을 보여준다.

**성공 기준**

 재추천 요청률과 재추천 이후 추천 사진 유지율을 측정한다.

**개발 준비 슬롯**

**선행조건**
- 해당 핀에 추천 결과가 존재한다.
- 핀에 연결된 사진이 4장 이상이다.

**트리거**
- 여행자가 핀 상세에서 재추천 받기를 선택한다.

**동작**
- 서비스는 해당 핀에 등록된 사진 전체를 요청 시점의 취향 프로파일로 스코어링한다.
- 서비스는 스코어 상위 10장을 재추천 후보로 추린다.
- 서비스는 후보 중에서 3장을 무작위로 선정해 추천 결과를 교체한다.
- 서비스는 추천 버전을 1 증가시켜 저장한다.

**결과**
- 여행자는 이전과 다른 구성의 대표 사진 3장을 확인한다.
- 서비스는 재추천 요청 이벤트와 추천 버전 변경 이벤트를 기록한다.

**예외**
- 핀에 연결된 사진이 3장 이하이면 재추천 받기를 제공하지 않는다.
- 핀에 등록된 사진이 10장 미만이면 등록된 사진 전체를 후보로 사용한다.
- 후보가 정확히 3장이면 무작위 선정 없이 그 3장을 그대로 사용하고, 더 제안할 조합이 없다는 안내를 표시한다.

**표시**
- 재추천을 처리하는 동안 처리 중 상태를 표시한다.
- 재추천이 완료되면 갱신된 대표 사진 3장을 표시한다.

**권한 & 접근**
- 여행자는 본인의 핀에 대해서만 재추천을 요청할 수 있다.

**비즈니스 규칙**
- 재추천 횟수에는 제한을 두지 않는다.
- 재추천 후보는 취향 프로파일 스코어 상위 10장으로 한정하며, 그 안에서 3장을 무작위로 선정한다.
- 직전 추천에 포함된 사진도 후보에 남으며 다시 선정될 수 있다.
- 재추천 요청과 그 결과는 취향 프로파일 학습에 반영하지 않는다.
- 재추천 스코어링에는 요청 시점의 최신 취향 프로파일을 사용한다.
- 취향 프로파일이 7.3 재학습이나 5.2.2 수정 신호로 바뀌어도 기존 추천 결과를 소급해 다시 계산하지 않으며, 여행자가 재추천을 요청한 핀에만 바뀐 프로파일이 적용된다.
- 이전 추천 결과는 보존하지 않고 최신 추천 결과로 교체한다.

**데이터**
- 추천 결과에는 핀 식별자, 사진 식별자, 추천 순서, 추천 버전, 적용 프로파일 버전, 재계산 시각을 저장한다.
- 재추천 이력에는 핀 식별자, 이전 추천 버전, 새 추천 버전, 후보 사진 수, 요청 시각을 저장한다.

#### 5.2.4 음성 메모 재생
여행자는 핀 상세와 포토북에서 해당 핀에 저장된 음성 메모를 재생해 촬영 당시 남긴 맥락을 다시 듣는다. 이 동작은 저장된 음성의 재생 제어에 한정하며, 음성 녹음과 저장은 8.2와 5.1.2에서 다룬다. **[v3.5 변경]**

**기능의 근거**

 텍스트로 옮겨 적은 기록은 그 순간의 어조와 즉흥성을 담지 못한다. 촬영 직후 남긴 목소리를 그대로 다시 들을 수 있어야 기록 맥락이 온전히 회수된다.

**성공 기준**

 음성 메모가 있는 핀에서의 재생률을 측정한다.

**개발 준비 슬롯**

**선행조건**
- 해당 핀에 저장된 음성 메모 파일이 존재한다.

**트리거**
- 여행자가 핀 상세 또는 포토북의 음성 재생 버튼을 선택한다.

**동작**
- 서비스는 저장된 음성 파일을 불러와 재생을 시작한다.
- 서비스는 재생 진행 위치와 전체 길이를 표시한다.
- 여행자는 재생 중 다시 선택해 일시정지하고, 재선택으로 이어서 재생한다.

**결과**
- 여행자는 촬영 당시 남긴 음성 맥락을 청취한다.
- 서비스는 음성 재생 시작 이벤트와 재생 완료 이벤트를 기록한다.

**예외**
- 음성 메모가 없는 핀에는 재생 버튼을 표시하지 않는다.
- 음성 파일을 불러오지 못하면 재생할 수 없다는 안내와 재시도 진입점을 표시한다.
- 다른 음성 재생 중에 새 음성을 선택하면 이전 재생을 중지하고 새 음성을 재생한다.

**표시**
- 재생 컨트롤은 재생·일시정지 아이콘, 진행 바, 전체 길이를 표시한다.
- 포토북에서는 재생 컨트롤을 사진에 겹치지 않는 작은 크기로 표시한다.
- 음성을 불러오는 동안 처리 중 상태를 표시한다.

**권한 & 접근**
- 여행자는 본인의 핀에 저장된 음성만 재생할 수 있다.

**비즈니스 규칙**
- 음성 메모가 없으면 재생 컨트롤 자체를 렌더링하지 않는다.
- 재생은 자동으로 시작하지 않으며 사용자가 선택했을 때만 시작한다.

**데이터**
- 음성 메모에는 핀 식별자, 음성 파일 식별자, 재생 길이, 녹음 경로(촬영 흐름 또는 수동 입력), 저장 시각을 조회한다. **[v3.5 변경]**

### 5.3 핀 전체 사진 보기 **[v3.5 개정]**
여행자는 핀 상세에서 이 핀의 모든 사진 보기를 선택해 해당 핀에 연결된 전체 사진을 확인하고, 사진을 추가하거나 삭제한다. 사진은 태깅 세션 단위로 묶여 세션마다 촬영 일시를 헤더로 하고 가로 스크롤 슬라이드로 나열된다. 이 기능은 사진 열람과 추가·삭제에 한정하며, 추천 선정은 5.2.1에서 다룬다.

**기능의 근거**

 추천 3장은 선별 노동을 줄이지만, 사용자가 그 핀에서 무엇을 찍었는지 전부 확인하고 싶은 순간이 있다. 잘못 찍힌 사진이나 남기고 싶지 않은 사진을 지울 수 없으면 전체 보기는 확인만 가능한 화면에 머물고, 추천 후보에도 계속 남는다.

**성공 기준**

 핀 상세에서 전체 사진 보기 진입률과 사진 삭제·추가 발생률을 측정한다.

**개발 준비 슬롯**

**선행조건**
- 여행자에게 사진이 연결된 핀 기록이 있다.

**트리거**
- 여행자가 핀 상세에서 이 핀의 모든 사진 보기를 선택한다.

**동작**
- 서비스는 핀에 연결된 사진을 태깅 세션 식별자 기준으로 묶는다.
- 서비스는 세션을 시작 시각 오름차순으로 정렬해 세로로 나열한다.
- 서비스는 각 세션의 촬영 일시를 헤더로 표시하고 해당 세션의 사진을 가로 스크롤 슬라이드로 배치한다.
- 여행자는 세션별 슬라이드를 좌우로 넘겨 사진을 확인한다.
- 여행자가 선택 모드로 진입하면 서비스는 사진별 선택 상태를 표시한다. **[v3.5 신설]**- 여행자가 선택한 사진의 삭제를 선택하면 서비스는 삭제 확인 안내를 표시하고, 확인하면 해당 사진을 핀에서 제거한다. **[v3.5 신설]**- 여행자가 우측 상단의 주변 사진 추가를 선택하면 서비스는 5.4 주변 사진 추가로 이동한다.
- 서비스는 사진 추가 또는 삭제 후 5.2.1 핀별 사진 추천의 재선정을 트리거한다. **[v3.5 신설]**

**결과**
- 여행자는 핀에 연결된 전체 사진을 촬영 세션 단위로 확인한다.
- 삭제한 사진은 핀 연결과 추천 대상, 포토북 수록 대상에서 제외된다. **[v3.5 신설]**- 서비스는 전체 사진 열람 이벤트, 사진 삭제 이벤트, 사진 추가 이벤트를 기록한다. **[v3.5 변경]**

**예외**
- 주변 사진 추가로 업로드된 사진은 태깅 세션에 속하지 않으므로 추가한 사진 세션으로 별도 묶어 마지막에 표시한다.
- 핀에 연결된 사진이 1장뿐이면 삭제 진입점을 비활성으로 표시하고, 마지막 사진은 삭제할 수 없다는 안내를 표시한다. **[v3.5 신설]**- 삭제하려는 사진이 현재 추천 결과에 포함되어 있으면 추천이 다시 계산된다는 사실을 확인 안내에 포함한다. **[v3.5 신설]**- 핀에 연결된 사진이 없으면 사진이 없다는 빈 상태와 주변 사진 추가 진입점을 표시한다. **[v3.5 변경]**- 사진 로딩에 실패한 항목은 자리를 유지하고 재시도 진입점을 표시한다.

**표시**
- 화면 상단에는 핀의 장소명을 표시하고, 우측에 주변 사진 추가 진입점과 선택 모드 진입점을 표시한다. **[v3.5 변경]**- 선택 모드에서는 선택한 사진 수와 삭제 진입점을 화면 하단에 표시한다. **[v3.5 신설]**- 각 세션 블록은 촬영 일시 헤더와 가로 스크롤 슬라이드, 스크롤 위치 표시자를 포함한다.
- 사진을 불러오는 동안과 삭제를 처리하는 동안 처리 중 상태를 표시한다. **[v3.5 변경]**

**권한 & 접근**
- 여행자는 본인의 핀에 연결된 사진만 조회하고 삭제할 수 있다. **[v3.5 변경]**

**비즈니스 규칙**
- 태깅 세션은 NFC 태깅 또는 수동 시작 시점부터 핀 저장 완료 시점까지 촬영한 사진의 묶음이다.
- 같은 핀에서 계속 촬영하기로 이어진 촬영은 새로운 세션으로 구분한다.
- 세션 정렬 기준은 세션 시작 시각이다.
- 사진 삭제는 해당 핀과의 연결을 끊는 것이며, 여행자의 기기 갤러리에 있는 원본에는 영향을 주지 않는다. **[v3.5 신설]**- 핀에는 최소 1장의 사진을 유지하며, 마지막 1장은 삭제할 수 없다. **[v3.5 신설]**- 사진을 삭제하거나 추가하면 해당 핀의 추천을 다시 선정한다. **[v3.5 신설]**

**데이터**
- 태깅 세션에는 세션 식별자, 핀 식별자, 시작 유형, 시작 시각, 종료 시각을 저장한다.
- 사진에는 사진 식별자, 핀 식별자, 세션 식별자, 촬영 시각, 좌표, 등록 경로(촬영 또는 업로드), 삭제 여부와 삭제 시각을 저장한다. **[v3.5 변경]**

### 5.4 주변 사진 추가
여행자는 핀을 기준으로 반경 1km 이내에서 촬영한 사진을 갤러리에서 선택해 같은 핀 기록에 추가한다. 이 기능은 반경 내 사진의 선택과 연결에 한정하며, 태깅하지 않은 사진을 자동으로 수집하거나 핀을 새로 생성하는 범위는 포함하지 않는다.

**기능의 근거**

 태깅 없이 일반 카메라로 찍은 사진이나 이전에 찍어둔 사진도 같은 장소의 기록이다. 이를 같은 핀에 합칠 수 있어야 추천 대상이 넓어지고, 즉시 촬영이 기본값이면서도 누락된 사진을 보완할 경로가 생긴다.

**성공 기준**

 주변 사진 추가 진입률과 추가 이후 추천 재선정 발생률을 측정한다.

**개발 준비 슬롯**

**선행조건**
- 여행자에게 좌표가 있는 저장된 핀이 하나 이상 있어야 한다.
- 여행자가 사진 라이브러리 접근을 허용해야 한다.

**트리거**
- 여행자가 5.2 핀 상세의 추천 사진 영역 우측 사진 추가 진입점을 선택한다.
- 여행자가 5.3 핀 전체 사진 보기의 우측 상단 주변 사진 추가를 선택한다.
- 여행자가 핀을 처음 열 때 표시되는 주변 사진 업로드 유도 문구에서 사진 선택을 선택한다.

**동작**
- 서비스는 핀 좌표를 기준으로 반경 1km 이내에서 촬영된 사진을 조회해 격자로 표시한다.
- 여행자는 추가할 사진을 여러 장 선택한다.
- 서비스는 선택한 사진 수를 실시간으로 표시한다.
- 여행자가 추가를 선택하면 서비스는 선택한 사진을 해당 핀에 연결한다.
- 서비스는 사진 추가 후 5.2.1 핀별 사진 추천의 재선정을 트리거한다.

**결과**
- 선택한 사진은 핀의 포함 사진 목록과 추천 대상에 추가된다.
- 서비스는 주변 사진 추가 이벤트와 추천 재선정 트리거 이벤트를 기록한다.

**예외**
- 반경 내 사진이 없으면 추가할 사진이 없다는 빈 상태를 표시한다.
- 이미 해당 핀에 연결된 사진은 목록에서 제외한다.
- 사진 라이브러리 접근이 거부되면 1.3 권한 거부·미지원 안내로 이동한다.
- 좌표가 없는 핀에서는 주변 사진 추가를 제공하지 않는다.

**표시**
- 화면 상단에는 핀의 장소명과 촬영 일시, 반경 1km 기준 안내 문구를 표시한다.
- 선택 영역은 선택한 사진 수를 표시한다.
- 사진은 격자 형태의 미리보기와 선택 상태로 표시한다.
- 사진 목록을 불러오는 동안과 추가를 저장하는 동안 처리 중 상태를 표시한다.

**권한 & 접근**
- 여행자는 자신의 핀에만 사진을 추가할 수 있다.
- 서비스는 주변 사진 조회를 위해 사진 라이브러리 접근 권한을 요청한다.

**비즈니스 규칙**
- 추가 가능한 사진은 핀 좌표 반경 1km 이내에서 촬영된 사진으로 제한한다.
- 사진은 여행자가 명시적으로 선택한 경우에만 핀에 추가한다.
- 업로드된 사진은 태깅 세션에 속하지 않으며 등록 경로를 업로드로 저장한다.

**데이터**
- 핀-사진 연결 정보는 핀 식별자, 사진 식별자, 등록 경로, 추가 시각으로 저장한다.
- 주변 사진 조회에는 사진의 촬영 시각과 촬영 좌표를 사용한다.

## 6 포토북 아카이브
여행자가 홈에서 여정을 종료하면 서비스는 여정별·도시별 포토북을 생성하고, 여행자는 아카이빙 페이지에서 이를 목록으로 열람한다. 이 영역은 여정 종료 시점의 포토북 생성, 포토북 목록과 커버 교체, 여정별 포토북 열람, 종료된 여정의 구간 관리 진입을 포함하며, 사용자의 직접 편집이나 인쇄 주문은 포함하지 않는다. **[v3.5 변경]**
- 여행자가 여정을 종료하면 서비스는 여정별·도시별 포토북을 생성한다.
- 여행자는 아카이빙 페이지에서 생성된 포토북 목록을 확인할 수 있다.
- 여행자는 여행별 포토북의 커버 이미지를 수록 사진 중에서 다시 뽑을 수 있다. **[v3.5 신설]**
- 여행자는 여정별 포토북에서 여정 동선 지도와 도시별로 선별된 핀의 사진·기록을 확인할 수 있다.
- 여행자는 아카이빙 목록에서 종료된 여정의 여행 구간 관리로 이동할 수 있다. **[v3.5 신설]**

### 6.1 포토북 아카이빙 목록 **[v3.5 개정]**
여행자는 아카이브 화면에서 생성된 포토북을 여행별과 도시별로 나누어 목록으로 확인하고 상세 포토북으로 이동한다. 여행별 포토북 항목에서는 커버 이미지를 새로 고치거나 해당 여정의 여행 구간 관리로 이동할 수 있다. 이 기능은 목록 표시와 진입점 제공, 커버 교체에 한정하며, 포토북의 생성 조건은 6.1.1에서 다룬다.

**기능의 근거**

 여행이 쌓일수록 개별 여정을 다시 찾기 어려워진다. 여행별과 도시별이라는 두 축으로 목록을 제공하면 사용자는 시간 기준과 장소 기준 중 자신에게 익숙한 방식으로 기록에 접근할 수 있다. 커버는 그 여정을 대표하는 얼굴이므로, 자동 선정 결과가 마음에 들지 않을 때 다시 뽑을 수단이 필요하다.

**성공 기준**

 아카이브 화면 방문율, 포토북 상세 진입률, 커버 새로고침 사용률을 측정한다.

**개발 준비 슬롯**

**선행조건**
- 여행자에게 생성된 포토북이 하나 이상 있다.

**트리거**
- 여행자가 하단 내비게이션에서 아카이브를 선택한다.

**동작**
- 서비스는 여행별 포토북을 종료일 내림차순으로 나열한다.
- 서비스는 도시별 포토북을 최근 방문 순으로 나열한다.
- 서비스는 각 포토북의 커버 이미지로 저장된 대표 사진을 표시한다. **[v3.5 신설]**- 여행자가 커버 이미지 우측 상단의 새로고침을 선택하면 서비스는 해당 포토북에 수록된 사진 중에서 현재 커버를 제외하고 1장을 무작위로 골라 커버로 교체한다. **[v3.5 신설]**- 서비스는 교체된 커버를 대표 사진으로 저장해 다음 진입 시에도 유지한다. **[v3.5 신설]**- 여행자가 여행별 포토북을 선택하면 서비스는 6.2 여정별 포토북으로 이동한다.
- 여행자가 여행별 포토북 항목의 여행 구간 관리를 선택하면 서비스는 4.1 여행 구간 목록·요약으로 이동한다. **[v3.5 신설]**

**결과**
- 여행자는 생성된 포토북 전체를 두 축으로 확인한다.
- 서비스는 아카이브 조회 이벤트, 포토북 선택 이벤트, 커버 새로고침 이벤트, 구간 관리 진입 이벤트를 기록한다. **[v3.5 변경]**

**예외**
- 생성된 포토북이 없으면 아직 완성된 여행이 없다는 빈 상태를 표시한다.
- 진행 중인 여정은 포토북이 생성되지 않았으므로 목록에 표시하지 않는다. **[v3.5 신설]**- 포토북에 수록된 사진이 1장뿐이면 커버 새로고침 진입점을 비활성으로 표시한다. **[v3.5 신설]**- 도시 정보가 없는 핀만으로 구성된 여정은 여행별 포토북에만 표시한다.

**표시**
- 여행별 포토북 항목은 커버 이미지, 여정 이름, 기간, 방문 도시와 사진 수, 여행 구간 관리 진입점을 표시한다. **[v3.5 변경]**- 커버 이미지 우측 상단에는 새로고침 진입점을 표시한다. **[v3.5 신설]**- 커버를 교체하는 동안 커버 영역에 처리 중 상태를 표시한다. **[v3.5 신설]**- 도시별 포토북 항목은 커버 이미지, 도시명, 사진 수, 방문 시기를 표시한다.
- 목록을 불러오는 동안 처리 중 상태를 표시한다.

**권한 & 접근**
- 여행자는 본인의 기록으로 생성된 포토북만 조회하고 커버를 교체할 수 있다. **[v3.5 변경]**

**비즈니스 규칙**
- 목록은 다이어리 형식으로 시간 흐름에 따라 나열한다.
- 목록에는 종료된 여정의 포토북만 표시하며, 진행 중인 여정은 커버 이미지를 두지 않는다. **[v3.5 신설]**- 커버 후보는 해당 포토북에 수록된 사진으로 한정하며, 수록되지 않은 사진은 커버가 될 수 없다. **[v3.5 신설]**- 커버 새로고침은 현재 커버를 제외한 나머지 수록 사진 중에서 무작위로 1장을 선정한다. **[v3.5 신설]**- 커버 새로고침 횟수에는 제한을 두지 않는다. **[v3.5 신설]**- 여행 구간 관리 진입점은 종료된 여정에 대해서만 제공한다. **[v3.5 신설]**- 하나의 여정에서 여행별 포토북 1개와 방문 도시 수만큼의 도시별 포토북이 생성된다.

**데이터**
- 포토북 목록에는 포토북 식별자, 분류 유형, 제목, 시작일, 종료일, 대표 사진 식별자, 사진 수를 조회한다.
- 커버 교체 시 포토북의 대표 사진 식별자와 교체 시각을 갱신해 저장한다. **[v3.5 신설]**

#### 6.1.1 여정 종료 시 포토북 생성
여행자가 홈에서 여정 종료하기를 선택하면 서비스는 여정 전체 포토북과 방문 도시별 포토북을 생성해 아카이빙 목록에 추가한다. 이 동작은 생성 처리에 한정하며, 종료 진입점은 3.1에서, 생성된 포토북의 열람은 6.2에서 다룬다.

**개발 준비 슬롯**

**선행조건**
- 여행자에게 하나 이상의 핀이 포함된 진행 중인 여행 구간이 있다.
- 서비스는 핀의 촬영 시각과 좌표를 보유한다.

**트리거**
- 여행자가 3.1 진행 중인 여정 요약에서 여정 종료하기를 선택하고 종료를 확인한다.
- 여행자가 4.2에서 구간 이름·기간·수록 핀을 변경해 저장한다. **[v3.5 신설]**

**동작**
- 서비스는 종료된 여행 구간의 첫 핀과 마지막 핀의 시각으로 여정 범위를 확정한다.
- 서비스는 4.2에서 수록 대상으로 지정된 핀만 포토북 생성 대상으로 삼는다. **[v3.5 신설]**- 서비스는 여정 전체를 대상으로 여행별 포토북을 생성한다.
- 서비스는 핀의 좌표에서 도출한 도시를 기준으로 도시별 포토북을 각각 생성한다.
- 서비스는 각 포토북의 대표 사진을 해당 포토북에 수록된 사진 중에서 무작위로 1장 선정해 커버로 저장한다. **[v3.5 변경]**- 서비스는 생성된 포토북을 아카이빙 목록에 추가한다.

**결과**
- 여행자는 여정을 종료한 직후 완성된 포토북을 아카이브에서 확인한다.
- 서비스는 여정 종료 이벤트와 포토북 생성 이벤트를 기록한다.

**예외**
- 도시 정보를 도출할 수 없는 핀은 여행별 포토북에만 포함한다.
- 좌표가 없는 핀의 사진은 포토북에 포함하되 도시 분류에서는 제외한다.
- 포함된 핀이 없는 여정은 종료할 수 없으므로 포토북을 생성하지 않는다.
- 이미 포토북이 생성된 여정에 핀이 추가되거나 수록 여부가 바뀌면 해당 포토북을 다시 생성한다. **[v3.5 변경]**- 포토북을 다시 생성할 때 기존 커버 사진이 여전히 수록 대상이면 커버를 유지하고, 수록에서 빠졌으면 새로 무작위 선정한다. **[v3.5 신설]**

**표시**
- 포토북을 생성하는 동안 아카이브 목록에 생성 중 상태를 표시한다.

**권한 & 접근**
- 여행자는 본인의 핀 기록으로 생성된 포토북만 조회한다.

**비즈니스 규칙**
- 여정 종료는 여행자의 명시적 선택으로만 발생하며 시간 경과로 자동 종료되지 않는다.
- 한 여정에 대해 여행별 포토북과 도시별 포토북을 함께 생성한다.
- 포토북 생성은 여정 종료가 확정된 시점에 즉시 시작한다.
- 포토북 커버는 수록된 사진 중 무작위 1장으로 선정하며, 6.1에서 여행자가 다시 뽑을 수 있다. **[v3.5 신설]**- 포토북에 수록하는 핀은 4.2에서 수록 대상으로 지정된 핀으로 한정한다. **[v3.5 신설]**

**데이터**
- 포토북에는 포토북 식별자, 여행자 식별자, 분류 유형, 제목, 시작일, 종료일, 대표 사진 식별자, 대표 사진 교체 시각, 포함 핀 식별자 목록, 생성 시각을 저장한다. **[v3.5 변경]**- 도시별 포토북에는 도시 식별자 또는 도시명을 함께 저장한다.

### 6.2 여정별 포토북
여행자는 하나의 여정 전체를 사진과 기록이 순서대로 배치된 포토북으로 열람한다. 상단에는 여정 이름·기간·총 일수와 방문 도시 목록, 여정 전체 동선 지도가 표시되고, 본문은 도시별 구획으로 나뉘어 선별된 핀의 사진과 텍스트 기록·음성 메모가 함께 배치되며, 하단에는 여정 통계가 표시된다. 이 기능은 열람에 한정하며 편집과 인쇄 주문은 포함하지 않는다.

**기능의 근거**

 지도는 공간을, 핀은 순간을 보여주지만 여행 전체를 하나의 서사로 되돌려주지는 못한다. 시간 순서로 정리된 포토북은 여정을 처음부터 끝까지 다시 읽게 하고, 매장 인화로 이어질 원본이 된다.

**성공 기준**

 여정별 포토북 열람률과 도시 이동 선택률을 측정한다.

**개발 준비 슬롯**

**선행조건**
- 해당 여정의 포토북이 생성되어 있다.

**트리거**
- 여행자가 6.1 아카이브 목록에서 여행별 포토북을 선택한다.

**동작**
- 서비스는 상단에 여정 이름, 기간, 총 일수를 표시한다.
- 서비스는 방문 도시를 칩 형태로 나열하고, 칩을 선택하면 해당 도시 구획으로 화면을 이동시킨다.
- 서비스는 여정 전체의 핀과 동선이 그려진 지도를 표제 영역에 표시한다.
- 서비스는 4.2에서 포토북 수록 대상으로 지정된 핀만 선별 대상으로 삼는다. **[v3.5 신설]**- 서비스는 도시별로 포토북에 실을 핀을 선별한다. 해당 도시의 수록 핀이 3개 이상이면 텍스트 기록 또는 음성 메모가 있는 핀을 우선 선택하고, 그래도 3개가 되지 않으면 나머지 핀 중 무작위로 채워 총 3개를 선별한다. 수록 핀이 2개 이하이면 해당 도시의 모든 수록 핀을 싣는다. **[v3.5 변경]**- 서비스는 선별된 핀마다 사전에 정의된 3종의 배치 양식 중 하나를 적용해 사진과 기록을 배치한다.
- 서비스는 본문을 도시별 구획으로 나누고, 각 구획에 선별된 핀의 사진과 그 핀의 텍스트 기록을 함께 배치한다.
- 여행자가 구획의 자세히를 선택하면 서비스는 해당 핀의 5.2 핀 상세로 이동한다.
- 서비스는 음성 메모가 있는 사진에 5.2.4 음성 메모 재생 컨트롤을 함께 표시한다.
- 서비스는 하단에 저장된 핀 수, 포토북 사진 수, 방문 도시 수를 표시한다.

**결과**
- 여행자는 여정 전체를 하나의 흐름으로 열람한다.
- 서비스는 포토북 열람 이벤트, 도시 칩 선택 이벤트, 음성 재생 이벤트를 기록한다.

**예외**
- 도시 정보가 없는 핀은 기타 구획으로 묶어 마지막에 배치한다.
- 텍스트 기록이나 음성 메모가 있는 수록 핀이 3개를 넘으면 그중에서 무작위로 3개를 선택한다. **[v3.5 변경]**- 4.2에서 수록 대상에서 제외한 핀은 선별 대상에서 빠지며, 제외 후 수록 핀이 없어진 도시 구획은 표시하지 않는다. **[v3.5 신설]**- 도시에 수록 핀이 하나도 없으면 해당 도시 구획을 표시하지 않는다. **[v3.5 변경]**- 텍스트 기록과 음성 메모가 모두 없는 사진은 사진만 배치한다.

**표시**
- 상단은 여정 이름, 기간, 총 일수 배지, 방문 도시 칩과 우측의 여행 구간 관리 진입점을 표시한다.
- 상단 아래에는 여정 전체 동선 지도를 표시한다.
- 각 핀 구획에는 자세히 진입점을 함께 표시한다.
- 각 도시 구획은 도시명을 소제목으로 두고 사진과 기록을 교차 배치한다.
- 음성 재생 컨트롤은 음성 메모가 있는 사진에만 표시한다.
- 하단은 저장된 핀 수, 포토북 사진 수, 방문 도시 수를 나란히 표시한다.
- 포토북을 불러오는 동안 처리 중 상태를 표시한다.

**권한 & 접근**
- 여행자는 본인의 포토북만 열람한다.

**비즈니스 규칙**
- 여정별 포토북은 도시별 구획을 시간 순서로 배치하는 정형 레이아웃을 사용한다.
- 포토북 선별 대상은 구간-핀 연결의 포토북 수록 여부가 참인 핀으로 한정한다. **[v3.5 신설]**- 4.2에서 수록 여부가 바뀌면 해당 여정의 포토북 선별을 다시 수행한다. **[v3.5 신설]**- 도시별 수록 핀 수는 최대 3개로 하고, 수록 핀이 2개 이하인 도시는 전부 수록한다. **[v3.5 변경]**- 핀 선별 우선순위는 텍스트 기록 또는 음성 메모를 보유한 핀이 1순위이며, 동순위 안에서는 무작위로 선택한다.
- 핀 배치는 사전에 정의한 3종 배치 양식을 순환 적용해 같은 모양이 연속되지 않게 한다.
- 선별 결과는 저장해 재방문 시 동일하게 표시하며, 해당 도시에 핀이 추가되거나 수록 여부가 바뀌면 다시 선별한다. **[v3.5 변경]**- 포토북에 포함되는 사진은 핀별 추천 사진을 기본으로 하며 사용자가 수정한 선별 결과를 반영한다.

**데이터**
- 포토북 열람에는 포토북 식별자, 포함 핀 식별자 목록, 핀별 추천 사진, 텍스트 기록, 음성 메모, 도시 정보, 동선 좌표를 조회한다.
- 도시별 선별 결과에는 포토북 식별자, 도시명, 선별된 핀 식별자 목록, 핀별 적용 배치 양식 번호, 선별 시각을 저장한다.

### 6.3 도시별 포토북 — 삭제됨
이 화면은 스코프에서 제외되었다. 도시별 포토북 데이터는 6.1.1에서 계속 생성하며 6.1 목록에만 표시한다.

## 7 마이페이지
여행자는 마이페이지에서 자신의 프로필과 누적 여행 통계, 취향 프로파일 시각화, 등록된 MCM 제품 목록, 계정 설정을 한 화면에서 관리한다. 이 영역은 프로필·통계·프로파일 요약과 제품·계정 설정을 포함하며, 여행 기록 편집이나 포토북 열람은 각 영역에서 다루므로 포함하지 않는다.
- 여행자는 마이페이지에서 자신의 프로필과 누적 통계(태깅 횟수·완료 여정 수·방문 도시 수)를 확인할 수 있다.
- 여행자는 자신의 취향 프로파일을 6개 축의 시각화로 확인할 수 있다.
- 여행자는 취향 프로파일을 재학습해 다시 설정할 수 있다.
- 여행자는 태깅만으로 자동 등록된 MCM 제품과 제품별 태깅 횟수를 확인할 수 있다.
- 여행자는 등록된 제품의 연결을 해제할 수 있으며, 해제해도 그 제품으로 남긴 기록은 그대로 유지된다. **[v3.5 신설]**
- 여행자는 카메라·위치·마이크 권한 상태를 확인하고 로그아웃할 수 있다.

### 7.1 프로필 및 여행 통계
여행자는 마이페이지 상단에서 구글 계정 프로필과 누적 여행 통계(태깅 횟수, 완료 여정 수, 방문 도시 수)를 확인한다. 이 기능은 프로필과 집계 지표의 표시에 한정하며, 개별 여행 기록의 조회는 다른 영역에서 다룬다.

**기능의 근거**

 서비스를 쓸수록 무엇이 쌓이는지 숫자로 보여야 재사용 동기가 생긴다. 태깅 횟수는 이 서비스만의 행동 단위이고, 완료 여정과 방문 도시는 여행 기록이 자산으로 축적되고 있음을 보여준다.

**성공 기준**

 마이페이지 방문율과 통계 확인 후 다른 기록 화면으로의 이동률을 측정한다.

**개발 준비 슬롯**

**선행조건**
- 여행자는 로그인한 상태이다.

**트리거**
- 여행자가 하단 내비게이션에서 마이페이지를 선택한다.

**동작**
- 서비스는 구글 계정의 표시 이름과 계정 유형을 표시한다.
- 서비스는 누적 태깅 횟수, 완료 여정 수, 방문 도시 수를 집계해 표시한다.

**결과**
- 여행자는 자신의 누적 활동 규모를 확인한다.
- 서비스는 마이페이지 조회 이벤트를 기록한다.

**예외**
- 집계할 기록이 없으면 각 지표를 0으로 표시한다.
- 프로필 이미지를 불러오지 못하면 기본 아바타를 표시한다.

**표시**
- 프로필 영역은 아바타, 표시 이름, 계정 유형을 표시한다.
- 통계 영역은 태깅 횟수, 완료 여정 수, 방문 도시 수를 카드 세 개로 나란히 표시한다.
- 집계를 불러오는 동안 처리 중 상태를 표시한다.

**권한 & 접근**
- 여행자는 본인의 프로필과 통계만 조회할 수 있다.

**비즈니스 규칙**
- 태깅 횟수는 NFC 태깅으로 생성된 태깅 세션의 총 개수로 집계한다.
- 완료 여정 수는 여행자가 종료한 여정의 수로 집계한다.
- 방문 도시 수는 핀 좌표에서 도출한 서로 다른 도시의 수로 집계한다.

**데이터**
- 통계 집계에는 태깅 세션 수, 종료된 여정 수, 고유 도시 수를 조회한다. **[v3.5 변경]**

### 7.2 취향 프로파일 시각화
여행자는 마이페이지에서 자신의 취향 프로파일을 6개 축의 양극 슬라이더로 확인한다. 각 축은 서로 반대되는 두 성향 사이에서 현재 프로파일의 위치를 보여준다. 이 기능은 프로파일의 읽기 전용 표시에 한정하며, 값의 변경은 7.3 재학습과 5.2.2 추천 수정을 통해서만 이루어진다.

**기능의 근거**

 취향 프로파일은 추천 결과 뒤에 숨어 있어 사용자가 무엇을 근거로 사진이 골라지는지 알 수 없다. 축을 그대로 보여주면 추천이 자의적이지 않다는 사실이 드러나고, 여행을 거듭하며 값이 움직이는 것을 통해 프로파일이 자산으로 쌓인다는 점이 확인된다.

**성공 기준**

 취향 프로파일 카드 노출 대비 재학습 진입률을 측정한다.

**개발 준비 슬롯**

**선행조건**
- 여행자는 취향 프로파일 온보딩을 완료했다.

**트리거**
- 여행자가 마이페이지에 진입한다.

**동작**
- 서비스는 저장된 취향 프로파일의 6개 축 값을 조회한다.
- 서비스는 각 축을 양극 슬라이더로 표시하고 현재 값의 위치를 표시한다.

**결과**
- 여행자는 자신의 사진 선호 기준을 축 단위로 확인한다.
- 서비스는 취향 프로파일 조회 이벤트를 기록한다.

**예외**
- 온보딩을 완료하지 않았으면 슬라이더 대신 온보딩 진입 안내를 표시한다.
- 특정 축의 값이 아직 산출되지 않았으면 해당 축을 중앙값 위치에 표시한다.

**표시**
- 6개 축은 밝은↔︎어두운, 선명한↔︎차분한, 웜↔︎쿨, 여백 많은↔︎꽉 찬, 클로즈업↔︎넓게, 정면↔︎뒷모습·옆모습으로 표시한다. **[0(왼쪽)~100(오른쪽)]**- 각 축은 양 끝에 성향 이름을 두고 그 사이에 현재 값 위치를 표시한다.
- 카드 우측 상단에는 재학습 진입점을 표시한다.
- 프로파일을 불러오는 동안 처리 중 상태를 표시한다.

**권한 & 접근**
- 여행자는 본인의 취향 프로파일만 조회할 수 있다.

**비즈니스 규칙**
- 슬라이더는 이 화면에서 직접 값을 조정할 수 있다.
- 프로파일 값은 온보딩 응답과 5.2.2 추천 사진 수정 신호의 누적으로 갱신된다.
- 서비스는 점수나 등급 형태의 수치를 노출하지 않는다.
- 프로파일 값이 바뀌어도 이미 생성된 추천은 소급 재계산하지 않으며, 5.2.3 재추천을 요청한 핀부터 새 값이 적용된다. **[v3.5 신설]**

**데이터**
- 취향 프로파일에는 여행자 식별자, 축 식별자, 축별 값, 프로파일 버전, 마지막 갱신 시각, 반영된 수정 신호 수를 저장한다. **[v3.5 변경]**

### 7.3 취향 재학습
여행자는 마이페이지의 재학습 진입점을 통해 취향 프로파일 온보딩을 다시 수행한다. 재학습을 완료하면 새 응답으로 프로파일이 교체되고 이전 프로파일과 누적된 수정 신호는 삭제된다. 재학습이 완료되기 전까지는 기존 프로파일을 그대로 유지해 추천에 사용한다. 이 기능은 재학습 진입과 프로파일 교체에 한정하며, 온보딩 자체의 동작은 2번 영역과 동일하다.

**기능의 근거**

 사진 취향은 시간에 따라 바뀌고, 온보딩 시점의 응답이 실제 기준과 어긋났을 수도 있다. 프로파일을 다시 설정할 경로가 없으면 어긋난 추천이 계속 반복된다.

**성공 기준**

 재학습 완료율과 재학습 이후 추천 사진 유지율의 변화를 측정한다.

**개발 준비 슬롯**

**선행조건**
- 여행자는 취향 프로파일을 보유한다.

**트리거**
- 여행자가 마이페이지 취향 프로파일 카드에서 재학습을 선택한다.

**동작**
- 서비스는 기존 프로파일이 교체된다는 사실을 안내하고 진행 여부를 확인받는다.
- 여행자가 진행을 선택하면 서비스는 2.1 기본 질문 온보딩부터 무드보드까지 전체 흐름을 다시 시작한다.
- 서비스는 재학습이 완료된 시점에 새 응답으로 프로파일을 교체하고 이전 프로파일을 삭제한다.
- 서비스는 프로파일 교체 시 프로파일 버전을 1 증가시킨다. **[v3.5 신설]**

**결과**
- 여행자는 갱신된 취향 프로파일로 이후 추천을 받는다.
- 서비스는 재학습 시작 이벤트와 완료 이벤트를 기록한다.

**예외**
- 재학습을 중간에 중단하면 기존 프로파일을 그대로 유지하고 교체하지 않는다.
- 재학습이 완료되기 전까지 기존 프로파일은 삭제하지 않고 추천 생성에 그대로 사용한다.
- 재학습 중단 상태에서 다시 진입하면 2.4 온보딩 이어하기를 적용한다.

**표시**
- 재학습 진입 시 기존 프로파일이 교체된다는 확인 안내를 표시한다.
- 재학습 완료 후에는 갱신된 슬라이더 값을 표시한다.
- 재학습 완료 안내에는 기존 추천은 그대로 유지되며 재추천을 요청한 핀부터 새 기준이 적용된다는 문구를 함께 표시한다. **[v3.5 신설]**

**권한 & 접근**
- 여행자는 본인의 프로파일만 재학습할 수 있다.

**비즈니스 규칙**
- 재학습이 완료되어야 프로파일을 교체하며, 중단 시에는 교체하지 않는다.
- 재학습 완료 시 이전 프로파일은 보존하지 않고 삭제하며, 이전 값으로 되돌릴 수 없다.
- 재학습 진행 중에는 기존 프로파일을 유지해 추천이 끊기지 않게 한다.
- 재학습 완료 시 누적된 추천 수정 신호는 초기화한다.
- 이미 생성된 추천 결과는 소급해 다시 계산하지 않으며, 이후 생성되는 추천과 5.2.3 재추천부터 새 프로파일을 적용한다. **[v3.5 변경]**

**데이터**
- 재학습 이력에는 여행자 식별자, 시작 시각, 완료 시각을 저장하며 이전 프로파일 값은 보관하지 않는다.
- 취향 프로파일은 여행자당 한 벌만 저장하며 재학습 완료 시 덮어쓴다.
- 재학습 중에는 기존 프로파일과 진행 중인 응답을 분리해 보관하고, 완료 시점에 진행 중인 응답만 프로파일로 남긴다.

### 7.4 내 MCM 제품 관리
여행자는 마이페이지에서 자신의 계정에 등록된 MCM NFC 제품 목록과 제품별 누적 태깅 횟수를 확인한다. 제품은 태깅 시 자동으로 등록되므로 이 화면에는 별도의 등록 진입점을 두지 않으며, 자동 등록 동작은 7.5에서, 연결 해제는 7.4.1에서 다룬다.

**기능의 근거**

 여러 제품에 태그가 들어 있을 때 어떤 제품으로 얼마나 기록했는지가 보이면, 태깅이라는 행동이 제품과 연결된 경험으로 인식된다. 이는 제품 보유가 서비스 이용으로 이어지는 관계를 사용자에게 확인시킨다.

**성공 기준**

 등록 제품 수 분포와 제품별 태깅 횟수 분포를 측정한다.

**개발 준비 슬롯**

**선행조건**
- 여행자는 로그인한 상태이다.

**트리거**
- 여행자가 마이페이지에 진입한다.

**동작**
- 서비스는 계정에 연결된 NFC 태그 목록을 조회한다.
- 서비스는 태그별로 제품 유형과 제품명, 해당 태그로 생성된 태깅 세션 수를 집계해 표시한다.
- 서비스는 제품 목록을 최초 등록 시각 내림차순으로 나열한다.

**결과**
- 여행자는 등록된 제품과 제품별 사용량을 확인한다.
- 서비스는 제품 목록 조회 이벤트를 기록한다.

**예외**
- 등록된 제품이 없으면 아직 등록된 제품이 없다는 빈 상태와, 제품에 태깅하면 목록에 자동으로 추가된다는 안내를 표시한다.
- 매핑 테이블에서 제품 정보를 조회하지 못한 태그는 태그 식별자와 함께 미확인 제품으로 표시한다.

**표시**
- 각 제품 항목은 제품 유형 아이콘, 제품명, 누적 태깅 횟수를 표시한다.
- 목록 하단에는 제품에 태깅하면 자동으로 등록된다는 안내 문구를 표시하며, 별도의 등록 진입점은 표시하지 않는다.
- 목록을 불러오는 동안 처리 중 상태를 표시한다.

**권한 & 접근**
- 여행자는 본인 계정에 등록된 태그만 조회할 수 있다.

**비즈니스 규칙**
- 태깅 횟수는 해당 태그로 시작된 태깅 세션의 수로 집계한다.
- 3.3 여행 계속하기와 5.1.2 지도에서 핀 수동 입력으로 생성된 세션은 제품별 태깅 횟수에 포함하지 않는다.
- 제품 등록은 사용자가 별도로 수행하지 않으며 7.5의 자동 등록으로만 이루어진다.

**데이터**
- 등록 태그에는 태그 식별자, 여행자 식별자, 제품 유형, 제품명, 등록 시각, 등록 경로(자동), 최초 태깅 시각을 저장한다.

#### 7.4.1 제품 연결 해제
여행자는 제품 목록에서 잘못 등록된 제품의 계정 연결을 해제한다. 연결을 해제해도 해당 태그로 저장된 핀과 사진은 삭제하지 않으며, 해제한 태그는 이후 같은 계정에서 태깅해도 다시 자동 등록되지 않는다.

**기능의 근거**

 자동 등록은 사용자의 확인을 받지 않으므로, 빌린 가방이나 매장 전시품에 한 번 태깅하면 본인 소유가 아닌 제품이 목록에 영구히 남는다. 등록 절차를 없앤 대가로 되돌릴 경로가 반드시 필요하다. 다만 제품을 목록에서 지우는 것과 그 제품으로 남긴 여행 기록을 지우는 것은 전혀 다른 일이므로, 해제는 연결만 끊는다.

**성공 기준**

 연결 해제 발생률과 해제 대상 제품의 누적 태깅 횟수 분포를 측정해, 자동 등록의 오등록 비율을 추정한다.

**개발 준비 슬롯**

**선행조건**
- 여행자 계정에 등록된 제품이 하나 이상 있다.

**트리거**
- 여행자가 7.4 제품 목록에서 특정 제품의 연결 해제를 선택한다.

**동작**
- 서비스는 해당 제품으로 저장된 핀과 사진은 삭제되지 않는다는 사실을 안내하고 진행 여부를 확인받는다.
- 여행자가 진행을 선택하면 서비스는 태그와 계정의 연결을 끊는다.
- 서비스는 해당 태그를 자동 등록 제외 목록에 추가한다.

**결과**
- 해제한 제품은 7.4 제품 목록에서 사라진다.
- 해당 태그로 생성된 태깅 세션은 유지되지만 제품별 태깅 횟수 집계 대상에서 제외된다.
- 해당 태그로 저장된 핀, 사진, 기록 맥락, 포토북은 그대로 유지되며 지도·핀 상세·아카이브에서 계속 조회된다. **[v3.5 신설]**- 서비스는 연결 해제 이벤트를 기록한다.

**예외**
- 연결 해제를 취소하면 아무것도 변경하지 않는다.
- 자동 등록 제외 목록에 있는 태그로 태깅하면 등록 없이 촬영과 핀 저장만 진행한다.

**표시**
- 각 제품 항목에 연결 해제 진입점을 표시한다.
- 진입점 문구는 삭제가 아닌 연결 해제로 표시해 기록이 지워진다는 오해를 막는다. **[v3.5 신설]**- 연결 해제 시 저장된 기록은 삭제되지 않는다는 확인 안내를 표시한다.

**권한 & 접근**
- 여행자는 본인 계정에 등록된 제품만 해제할 수 있다.

**비즈니스 규칙**
- 연결 해제는 태그와 계정의 연결만 끊으며 핀·사진·기록 맥락·포토북 데이터는 보존한다. **[v3.5 변경]**- 해제한 태그는 자동 등록 제외 목록에 남아 같은 계정에서 다시 자동 등록되지 않는다.
- 다른 계정이 해당 태그를 태깅하면 7.5에 따라 그 계정에 자동 등록될 수 있다.

**데이터**
- 자동 등록 제외 목록에는 여행자 식별자, 태그 식별자, 해제 시각을 저장한다.

### 7.5 NFC 태그 자동 등록
여행자가 아직 계정에 등록되지 않은 MCM NFC 제품에 태깅하면, 서비스는 별도의 등록 절차 없이 해당 태그를 여행자 계정에 자동으로 연결한다. 자동 등록은 촬영 흐름을 지연시키지 않는 백그라운드 처리이며, 등록 이후의 촬영·핀 저장은 8번 영역에서 다룬다.

**기능의 근거**

 등록이라는 별도 단계는 사용자에게 아무런 가치를 주지 않으면서 태깅에서 촬영까지의 무마찰 흐름만 깨뜨린다. 태깅 행위 자체가 제품 보유의 증거이므로 시스템이 판단할 수 있는 일을 사용자에게 묻지 않는다. 이는 조작을 최소화하는 Quiet Tech 원칙과도 일치한다.

**성공 기준**

 자동 등록 성공률과, 태깅에서 카메라 화면 표시까지의 소요 시간이 자동 등록 유무에 따라 차이가 없는지를 측정한다.

**개발 준비 슬롯**

**선행조건**
- 여행자는 로그인한 상태이다.
- 태깅된 태그가 여행자 계정에 아직 등록되어 있지 않다.
- 서비스는 태그 식별자와 제품 정보를 연결하는 매핑 테이블을 보유한다.

**트리거**
- 여행자가 8.1 NFC 태깅 후 사진 촬영에서 미등록 태그로 태깅한다.

**동작**
- 서비스는 태그 식별자가 현재 계정에 등록되어 있는지, 자동 등록 제외 목록에 있는지 조회한다.
- 서비스는 조회 결과와 무관하게 카메라 화면을 즉시 연다.
- 서비스는 미등록 태그이면 촬영 흐름과 병행해 해당 태그를 계정에 연결한다.
- 서비스는 매핑 테이블에서 태그 식별자에 대응하는 제품 유형과 제품명을 조회해 함께 저장한다.

**결과**
- 새 태그가 여행자 계정에 등록되어 7.4 제품 목록에 추가된다.
- 해당 태깅으로 생성된 세션은 등록된 제품의 태깅 횟수에 포함한다.
- 서비스는 자동 등록 이벤트를 기록한다.

**예외**
- 이미 본인 계정에 등록된 태그이면 등록 처리를 건너뛰고 촬영 흐름만 진행한다.
- 다른 계정에 등록된 태그이면 등록하지 않고 촬영과 핀 저장은 그대로 진행하며, 해당 세션은 제품별 태깅 횟수에 포함하지 않는다.
- 자동 등록 제외 목록에 있는 태그이면 등록하지 않고 촬영과 핀 저장만 진행한다.
- 매핑 테이블에 없는 태그는 태그 식별자만으로 등록하고 7.4에 미확인 제품으로 표시한다.
- 등록 처리에 실패해도 촬영과 핀 저장은 중단하지 않으며, 다음 태깅 시 재시도한다.

**표시**
- 자동 등록을 위한 별도 화면이나 확인 절차를 표시하지 않는다.
- 최초 등록이 이루어진 경우에 한해 8.2 저장 완료 화면에 등록된 제품명을 한 줄로 표시한다.
- 등록 처리 중임을 알리는 대기 상태나 진행 표시를 노출하지 않는다.

**권한 & 접근**
- 태그 인식에는 8.1과 동일한 NFC 접근 조건을 따른다.
- 여행자는 본인 계정에만 태그를 등록할 수 있다.

**비즈니스 규칙**
- 하나의 태그는 하나의 계정에만 등록할 수 있으며, 최초로 태깅한 계정에 귀속된다.
- 자동 등록은 태깅 흐름을 차단하거나 지연시키지 않는다.
- 이미 다른 계정에 등록된 태그로도 촬영과 핀 저장은 제한하지 않는다.
- 제품 유형과 제품명은 사전에 구축한 태그-제품 매핑 테이블에서만 조회하며, 사용자가 직접 입력하지 않는다.
- 3.3 여행 계속하기와 5.1.2 지도에서 핀 수동 입력은 태그를 사용하지 않으므로 자동 등록을 발생시키지 않는다.

**데이터**
- 태그-제품 매핑 테이블에는 태그 식별자, 제품 유형, 제품명, 등록 시각을 저장한다.
- 등록 태그에는 태그 식별자, 여행자 식별자, 제품 유형, 제품명, 등록 시각, 등록 경로(자동)를 저장한다.

### 7.6 기기 권한 상태 확인 (카메라·위치·마이크)
여행자는 마이페이지의 계정 영역에서 카메라·위치·마이크 권한의 현재 상태를 한 곳에서 확인하고, 항목을 선택해 기기 설정으로 이동한다. 이 기능은 상태 표시와 설정 이동에 한정하며, 최초 권한 요청은 1.2에서, 거부 시의 기능별 영향 안내는 1.3에서, 음성 메모 실행 시점의 재확인은 8.2에서 다룬다.

**기능의 근거**

 권한이 꺼진 상태에서 발생하는 증상(태깅해도 촬영이 시작되지 않음, 핀이 지도에 표시되지 않음, 음성 메모 진입점이 눌리지 않음)은 사용자에게 기록 자체의 오류로 오해된다. 권한별 현재 상태를 상시 확인할 수 있는 단일 지점이 있어야 원인을 사용자가 스스로 짚을 수 있다.

**성공 기준**

 권한별 항목 선택률과 선택 후 허용 전환율을 측정한다.

**개발 준비 슬롯**

**선행조건**
- 여행자는 로그인한 상태이다.

**트리거**
- 여행자가 마이페이지에 진입한다.

**동작**
- 서비스는 기기의 카메라·위치·마이크 권한 상태를 각각 조회해 허용됨 또는 거부됨으로 표시한다.
- 서비스는 각 권한 항목에 해당 권한이 꺼져 있을 때 제한되는 기능을 한 줄로 함께 표시한다.
- 여행자가 항목을 선택하면 서비스는 기기 설정 화면으로 이동하도록 안내한다.

**결과**
- 여행자는 권한별 상태를 확인하고 필요 시 변경한다.
- 서비스는 권한 상태 조회 이벤트와 권한별 설정 이동 선택 이벤트를 기록한다.

**예외**
- 권한 상태를 조회할 수 없으면 확인 불가로 표시한다.
- 기기가 해당 권한을 지원하지 않으면 미지원으로 표시하고 설정 이동을 제공하지 않는다.

**표시**
- 각 항목은 권한 이름, 현재 상태, 제한되는 기능 안내, 이동 표시자를 함께 표시한다.
- 카메라 권한 항목에는 태깅 후 촬영을 할 수 없다는 안내를 표시한다.
- 위치 권한 항목에는 핀이 지도와 동선에 표시되지 않는다는 안내를 표시한다.
- 마이크 권한 항목에는 촬영 후 음성 메모를 남길 수 없다는 안내를 표시한다.

**권한 & 접근**
- 권한의 최종 허용 여부는 기기 운영체제 설정에서 결정된다.

**비즈니스 규칙**
- 카메라 권한은 촬영에 필수이며, 거부 상태에서는 태깅해도 촬영 흐름을 시작하지 않는다.
- 위치 권한이 거부된 상태에서도 촬영과 핀 저장은 가능하며 좌표만 저장하지 않는다.
- 위치 권한이 거부되어도 5.1.2 수동 핀 입력의 지도 드래그로는 좌표를 지정할 수 있다. **[v3.5 신설]**- 마이크 권한이 거부된 상태에서도 촬영과 핀 저장은 가능하며, 맥락 입력은 텍스트 기록으로만 이루어진다.
- 서비스는 이 화면에서 권한을 직접 요청하지 않고 기기 설정으로만 이동시킨다.

**데이터**
- 권한 상태는 여행자 기기에서 카메라·위치·마이크 각각의 허용·거부·미지원 상태로 조회한다.

## 8 NFC 태깅 및 핀 저장
여행자는 MCM NFC 태그에 휴대폰을 대어 촬영을 시작하고, 촬영한 사진과 위치·시각·맥락을 하나의 핀으로 저장한다. 이 영역은 태깅 후 사진 촬영과 핀 저장·맥락 입력을 포함하며, 태깅하지 않은 사진의 자동 수집은 포함하지 않는다.
- 여행자는 NFC 태깅 후 즉시 사진을 촬영할 수 있다.
- 여행자는 촬영한 사진과 위치·시각 정보를 포함한 핀을 저장할 수 있다.
- 여행자는 핀에 텍스트 기록과 음성 메모를 각각 하나씩 남길 수 있다. **[v3.5 변경]**
- 여행자는 저장 완료 후 같은 핀에 이어서 촬영할 수 있다.

### 8.1 NFC 태깅 후 사진 촬영
여행자가 MCM NFC 태그에 휴대폰을 대면 서비스가 실행되고 카메라 화면이 즉시 열려 촬영할 수 있다. 여행자는 한 세션에서 여러 장을 연속으로 촬영한 뒤 촬영 완료를 선택해 핀 저장 단계로 이동한다. 이 기능은 태깅에서 촬영 종료까지에 한정하며, 맥락 입력과 저장은 8.2에서 다룬다.

**기능의 근거**

 여행 중에는 손에 짐과 음료, 지도가 있어 잠금 해제에서 앱 진입까지의 여러 단계를 거치는 사이 순간을 놓친다. 태깅 한 번으로 촬영 상태까지 직행하는 흐름이 이 서비스의 핵심 차별점이며, 이 마찰 제거가 기록의 발생 빈도를 결정한다.

**성공 기준**

 태깅 대비 촬영 시작률과 태깅에서 첫 셔터까지의 소요 시간을 측정한다.

**개발 준비 슬롯**

**선행조건**
- 여행자는 MCM NFC 태그가 있는 제품을 소지한다.
- 여행자는 카메라 권한을 허용한 상태이다.

**트리거**
- 여행자가 MCM NFC 태그에 휴대폰을 댄다.
- 여행자가 3.3 여행 계속하기를 선택한다. **[v3.5 변경]**

**동작**
- 서비스는 태그가 전달한 주소로 실행되어 새 태깅 세션을 생성한다.
- 서비스는 진행 중인 여정이 있으면 해당 여정에 세션을 연결하고, 없으면 새 여정을 생성해 진행 중 상태로 둔 뒤 연결한다.
- 서비스는 세션 생성과 동시에 카메라 화면을 열고 셔터를 사용할 수 있는 상태로 둔다.
- 서비스는 세션 시작 시점에 위치 좌표를 확보한다.
- 여행자는 셔터를 눌러 한 장 이상 촬영한다.
- 여행자가 촬영 완료를 선택하면 서비스는 세션을 종료하고 8.2 핀 저장 및 맥락 입력으로 이동한다.

**결과**
- 서비스는 세션에서 촬영한 사진을 하나의 태깅 세션으로 묶는다.
- 서비스는 태깅 완료 이벤트, 촬영 이벤트, 세션 종료 이벤트를 기록한다.

**예외**
- 서비스는 NFC 태그를 읽지 못하면 3.3 여행 계속하기 또는 5.1.2 지도에서 핀 수동 입력을 대체 경로로 안내한다. **[v3.5 변경]**- 카메라 권한이 거부되면 1.3 권한 거부·미지원 안내로 이동한다.
- 위치 권한이 거부되면 좌표 없이 세션을 진행한다.
- 한 장도 촬영하지 않고 촬영 완료를 선택하면 핀을 저장하지 않고 이전 화면으로 돌아간다.

**표시**
- 촬영 화면은 카메라 미리보기와 셔터, 촬영 완료 진입점을 표시한다.
- 촬영한 사진 수를 화면에 표시한다.
- 카메라를 초기화하는 동안 처리 중 상태를 표시한다.

**권한 & 접근**
- 서비스는 사진 촬영을 위해 카메라 권한을 요청한다.
- 서비스는 촬영 위치 저장을 위해 위치 권한을 요청한다.

**비즈니스 규칙**
- 태깅 1회는 태깅 세션 1개를 생성한다.
- 진행 중인 여정이 없는 상태의 첫 태깅은 새 여정을 시작한다.
- 종료된 여정에는 새 태깅 세션을 연결하지 않는다.
- 한 세션에서 촬영할 수 있는 사진 수에는 제한을 두지 않는다.
- 5.1.2 수동 핀 입력은 이 촬영 흐름을 사용하지 않으며 별도의 업로드 흐름으로 처리한다. **[v3.5 신설]**- 서비스는 촬영 파이프라인에서 사진 파일의 촬영 위치 정보가 생성되지 않으므로, 세션 시작 시점의 위치 좌표를 별도 필드로 저장한다.

**데이터**
- 태깅 세션에는 세션 식별자, 시작 유형, NFC 태그 식별자, 시작 시각, 종료 시각, 좌표를 저장한다.
- 사진에는 사진 식별자, 세션 식별자, 촬영 시각, 등록 경로를 저장한다.

### 8.2 핀 저장 및 맥락 입력
여행자는 촬영을 마친 뒤 저장 완료 화면에서 텍스트 기록과 음성 메모를 남기고 핀을 저장한다. 저장된 핀은 사진, 좌표, 시각, 텍스트 기록, 음성 메모를 포함하며 추천 생성을 트리거한다. 여행자는 저장 후 홈으로 이동하거나 같은 핀에 이어서 촬영할 수 있다.

**기능의 근거**

 셔터를 누르게 만든 이유는 그 자리에서 붙잡지 않으면 며칠 안에 사라진다. 촬영 직후 텍스트와 음성으로 맥락을 남길 수 있어야 사진이 왜 찍혔는지가 기록에 함께 저장된다. 다만 하나의 핀은 하나의 순간이므로 맥락도 하나면 충분하며, 여러 개를 허용하면 어느 것이 그 순간의 기록인지 흐려진다.

**성공 기준**

 맥락 입력 완료율(텍스트 또는 음성 중 하나 이상)과 계속 촬영하기 선택률을 측정한다.

**개발 준비 슬롯**

**선행조건**
- 여행자가 8.1에서 한 장 이상을 촬영하고 촬영 완료를 선택했다.

**트리거**
- 서비스가 촬영 세션 종료 후 저장 완료 화면을 연다.

**동작**
- 서비스는 촬영한 사진, 좌표, 시각을 저장된 항목으로 요약해 표시한다.
- 여행자는 추가 기록 영역에 텍스트를 입력한다.
- 여행자는 음성 메모 남기기를 선택해 음성을 녹음한다.
- 서비스는 텍스트 기록과 음성 메모를 각각 1개만 받으며, 이미 저장된 기록이 있으면 새로 추가하지 않고 기존 내용을 표시한다. **[v3.5 신설]**- 여행자는 저장 전 텍스트 입력란의 내용을 자유롭게 고쳐 쓸 수 있다. **[v3.5 신설]**- 여행자는 텍스트와 음성을 함께 남기거나 각각만 남기거나 둘 다 남기지 않을 수 있다.
- 서비스는 사진, 좌표, 시각, 텍스트 기록, 음성 메모를 하나의 핀으로 저장한다.
- 서비스는 핀 저장 완료를 트리거로 5.2.1 핀별 사진 추천의 추천 생성을 시작한다.
- 여행자가 계속 촬영하기를 선택하면 서비스는 같은 핀에 연결되는 새 태깅 세션을 생성하고 촬영 화면으로 돌아간다.
- 여행자가 홈으로를 선택하면 서비스는 홈으로 이동한다.

**결과**
- 서비스는 사진·좌표·시각·맥락을 포함한 핀을 저장한다.
- 저장된 핀은 5.1 지도 뷰와 5.2 핀 상세에서 조회할 수 있다.
- 서비스는 핀 저장 이벤트, 맥락 입력 유형 이벤트, 계속 촬영 선택 이벤트를 기록한다.

**예외**
- 위치 권한이 거부되었거나 좌표를 확보하지 못하면 좌표 없이 핀을 저장하고, 해당 핀은 지도와 동선에서 제외한 뒤 4.1 여행 구간 관리의 포함된 핀 목록에 위치 정보 없음 상태로 표시한다.
- 마이크 권한이 거부된 상태에서는 음성 메모 진입점을 비활성으로 표시하고, 그 자리에 권한이 꺼져 있다는 상태 안내와 기기 설정으로 이동하는 진입점을 함께 표시하며 텍스트 입력은 그대로 제공한다.
- 여행자가 설정에서 마이크를 허용한 뒤 화면으로 돌아오면 서비스는 권한 상태를 다시 조회해 음성 메모 진입점을 활성화하고, 입력 중이던 텍스트는 그대로 유지한다.
- 마이크 권한이 아직 한 번도 요청되지 않은 상태에서 음성 메모를 선택하면 그 시점에 기기 권한을 요청한다.
- 계속 촬영하기로 돌아온 뒤 저장 완료 화면에 다시 진입하면, 이미 저장된 텍스트 기록과 음성 메모를 그대로 표시하고 새 기록을 추가로 받지 않는다. **[v3.5 신설]**- 이미 음성 메모가 저장된 핀에서는 음성 메모 남기기 진입점을 비활성으로 표시하고, 저장된 음성의 재생 컨트롤만 표시한다. **[v3.5 신설]**- 저장에 실패하면 입력한 내용을 유지한 채 재시도 진입점을 표시한다.
- 좌표로 장소명을 확인할 수 없으면 좌표만 저장하고 장소명은 비워 둔다.

**표시**
- 화면 상단은 저장 완료 안내와 대표 사진을 표시한다.
- 추가 기록 영역은 텍스트 입력란과 음성 메모 남기기 진입점을 함께 표시한다.
- 이미 저장된 음성 메모가 있으면 다시 녹음할 수 없다는 안내를 재생 컨트롤 아래에 표시한다. **[v3.5 신설]**- 마이크 권한이 거부된 경우 음성 메모 진입점 자리에 비활성 상태와 설정으로 이동 진입점을 표시한다.
- 기기가 마이크를 지원하지 않으면 음성 메모 진입점을 표시하지 않고 텍스트 입력만 표시한다.
- 저장된 항목 영역은 사진 수, 위치, 시각을 표시한다.
- 화면 하단은 홈으로와 계속 촬영하기 진입점을 표시한다.
- 저장을 처리하는 동안 처리 중 상태를 표시한다.

**권한 & 접근**
- 마이크 권한은 1.2 권한 안내 및 요청에서 사전에 요청하며, 이 화면에서는 현재 권한 상태를 확인해 음성 메모 사용 가능 여부를 판단한다.
- 서비스는 음성 메모를 녹음하는 동안에만 마이크를 사용하며 백그라운드에서 녹음하지 않는다.
- 여행자는 본인의 핀만 저장하고 조회할 수 있다.

**비즈니스 규칙**
- 텍스트 기록과 음성 메모는 각각 선택 사항이며 함께 남길 수 있다. **[v3.5 변경]**- 핀 하나에는 텍스트 기록 1개와 음성 메모 1개만 저장하며, 계속 촬영하기로 세션이 늘어나도 기록 맥락은 핀 단위로 하나씩만 유지한다. **[v3.5 신설]**- 텍스트 기록은 저장 이후에도 5.2 핀 상세에서 수정할 수 있다. **[v3.5 신설]**- 촬영 흐름에서 녹음한 음성 메모는 저장 이후 수정하거나 다시 녹음할 수 없다. **[v3.5 신설]**- 마이크 권한이 없어도 핀 저장 자체는 차단하지 않으며 맥락 입력 수단만 제한한다.
- 음성 메모 진입점의 활성·비활성은 저장된 값이 아니라 화면 진입 시점의 기기 권한 상태와 기존 음성 메모 존재 여부로 매번 판단한다. **[v3.5 변경]**- 음성 메모는 텍스트로 변환해 저장하되 원본 음성도 함께 보관해 5.2.4에서 재생할 수 있게 한다.
- 계속 촬영하기로 이어진 촬영은 같은 핀에 연결되며 새로운 태깅 세션으로 구분한다.
- 핀의 좌표는 첫 태깅 세션 시작 시점의 좌표를 사용한다.
- 추천 결과는 핀 저장이 완료된 뒤에 생성한다.

**데이터**
- 핀에는 핀 식별자, 여행자 식별자, 세션 식별자 목록, 사진 식별자 목록, 촬영 시각, 좌표, 장소명, 텍스트 기록, 텍스트 기록 마지막 수정 시각, 음성 메모 식별자, 음성 녹음 경로(촬영 흐름 또는 수동 입력), 음성 변환 텍스트, 저장 시각을 저장한다. **[v3.5 변경]**

# 부록. 결정 필요 사항

1. **수동 핀이 과거 날짜일 때의 여정 귀속** — 현재 규칙은 “진행 중 여정이 있으면 포함, 없으면 새 여정 생성”이다. 과거 날짜로 수동 핀 하나를 만들면 그 핀이 새 여정을 시작하게 된다.
2. **음성 메모 수정 불가 범위** — 촬영 흐름(8.2)에서 녹음한 음성만 수정 불가로 정의했다. 5.1.2 수동 입력에서 녹음한 음성도 동일하게 막을지 확인 필요.
3. **도시별 포토북의 열람 경로** — 6.3이 삭제되어 도시별 포토북은 생성되지만 상세 열람 화면이 없다. 생성을 함께 중단할지, 6.1 목록 표시만 유지할지 결정 필요.
4. **태그-제품 매핑 시드 데이터** — 데모용 NTAG UID와 제품명을 확정하지 않으면 자동 등록이 전부 미확인 제품으로 표시된다.
